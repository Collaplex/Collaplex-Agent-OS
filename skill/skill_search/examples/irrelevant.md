# 例：不相关的查询

真实抓取的输出，不是手写的。

**阈值默认是 `null`（不过滤）**，所以不相关的查询也会拿到 top-k —— 看分数自己判断。
想让它只返回够格的，把 `resources/skill_index.json` 的 `hit_threshold` 设成数字。

```
$ .venv/bin/python skill/skill_search/main.py find "今天晚饭吃什么"

查询: 今天晚饭吃什么
索引 3 个 skill
----------------------------------------------------------------
[1] 相似度 0.3411   seek
    目录: skill/seek
    描述: 模型默认思考技能，模仿人的自然思考方式
----------------------------------------------------------------
[2] 相似度 0.3343   skill_search
    目录: skill/skill_search
    描述: skill 检索：给一句话，找出该用哪个 skill，返回命中的 skill 描述和相对目录。
----------------------------------------------------------------
[3] 相似度 0.3220   rag
    目录: skill/rag
    描述: 资料检索。把问题丢进来，拿回最相关的原文片段；只回原文，不做推理和总结。
----------------------------------------------------------------
```

看点：三条分数都掉到 0.3 附近，且没有一条真正对得上 —— 这就是「库里没有」的样子。
