# 网页版 · 界面与设置页

**用途**：浏览器里说话的那条链，界面上叫 **Collaplex Agent OS**。它跟命令行**共用同一条链**（web 只搬运，业务规则一条都不在 web 里）。

**用法**
- 起：`collaplex-agent web`，或 `./.venv/bin/python -m web.server --端口 8791`
- 界面：左栏 = 图标 + **历史记录**（全量跳点，点哪条滚到那一轮）+ 底部**设置**；右栏 = 对话
- 设置页共八节（左栏一排入口，点哪个右区换哪个）：
  **接口**（四条模型接口写 `.env`，改前自动备份）
  **开关**（五个开关写各自 json，每轮现读，不用重启）
  **Skill**（各 skill 开关 + 搜索，用的是模型挑 skill 那同一套算法）
  **数据库**（三层合成一张表，切 tier / 按来源过滤 + 手动搜索）
  **定时任务** / **日志**（分类看尾巴，自动刷）/ **现状**（只读）/ **关闭**（不可逆，点第二下才动手）
- 历史存档 `state/web-对话.jsonl`（每轮 问 + 答 + 过程 一行，过程也入库）

**备注**：动了 `web/server.py` **必须重启 web 进程**（页面 F5 没用）。输入栏可以**拖**本机文件/文件夹进来，或用回形针按钮（`Ctrl+O`）翻目录选，都会填成**带引号**的路径（浏览器不给 `<input type=file>` 真路径，所以是本机服务去列目录，只读）。「关闭」节关模型会先停看门狗再停，并落 `state/停机`；关 web 是延迟 1.5 秒再退，免得页面只看到连接重置。
