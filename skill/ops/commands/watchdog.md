# 看门狗 · 盯四个服务

**用途**：`watchdog.py` 每 30 秒看一眼 **主模型 8790 / 向量 8199 / web 8791 / PG**，谁挂了拉谁。由启动页「以本地模型启动」挂上（也可以手动起）。

**用法**
- 手动起：`./.venv/bin/python watchdog.py --间隔 30 --web端口 8791`
- 看它在说什么：`tail -n 40 logs/watchdog.log`（它自己往这份日志写，stdout/stderr 都被丢掉了）
- 判它有没有在跑：`pgrep -af watchdog.py`

**备注**
- ★ **关模型要先停看门狗**：不停它，30 秒后它把模型拉回来，用户以为按钮坏了。设置页「关闭」节就是这么做的。
- ★ 已经有一个在跑时**不重复挂**（启动页会打"看门狗已经在跑"）；重复挂的表现是同一行"上岗"日志出现好几遍。
- 用它替代"定时检查服务"那类 cron：它认得四个服务各自的判活方式（PG 看 socket 答话、模型看 HTTP 答话）。
