# 定时任务 · 闹钟与倒计时

**用途**：`「过一会儿 / 到某个点再提醒我」`都走 `skill/timer`。它**只提醒，不替你干活** —— 到点把提醒交回主 agent。

**用法**
- `./.venv/bin/python skill/timer/main.py register "30分钟后提醒我关火, 先去忙别的"`
- `… register "下午3点提醒我开会, 等着"`　带"等着"= **阻塞式**：就在这一轮对话里等，逐秒读秒（硬上限 180 分钟）
- `… register "25分钟后提醒我关火" --json --阻塞`
- `… list` / `… cancel --最近` / `… take --json` / `… status` / `… selfcheck`

**怎么落地（框架侧 `定时.py`）**
- `重挂()`：进程起来时读回表、过期条目补一次、有活就把定时器线程起在**本进程**里（skill 子进程登记完就退，起不了线程）
- `取待办()`：每轮开场拉一次 —— 到点的搬出来拼成开场话（**非阻塞**那条路）
- `等阻塞(条)`：这一轮登记了阻塞式就在这里等，每秒回调读秒
- 提醒是**拉式**：到点先标"到点待注入"，下一轮开场交付 ⇒ 进程刚重启也不会漏

**备注**：表落**冷库**（PG 表 `timers`，按进程键分行：web / cli 各一行）；`SKILL.md` 里写的语义（阻塞/非阻塞、硬上限）以 `skill/timer/` 现读为准。定时类 skill 的坑（提醒注入**不能带指令**、两个钟的语义）见项目文档与技能库。
