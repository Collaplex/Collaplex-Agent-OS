# 清洗管线 · 把热库下沉成历史对话层 + 经验层

**用途**：`skill/rag/scripts/refine.py` 干三件事 —— ① 把热库里的对话产出**原样搬进 tier 1**（永久留）② 洗出概述 / 知识 / 别名进 **tier 3** ③ 把那批对话产出从 tier 2 清掉、删 `corpus/` 里的原文。项目静态语料一行不动。

**怎么跑（都在项目根）**
- `./.venv/bin/python skill/rag/scripts/refine.py`　**不带给参数进的是「看守」模式**：按静默判据决定动不动，最常见的输出是 `[看守] 不动: 这批已经清过了`
- `… refine.py --强制`　不看静默判据、**立刻清**（要一次把手头的活清完就用它）
- `… refine.py --干跑`　只列要清什么，不动库
- `… refine.py --待重洗`　看洗不了的账；`--回填`　补洗半成品（有原文没概述）
- `… refine.py --本地`　★ 钉死本机 `127.0.0.1:8790`：**清洗是长跑批处理，必须走本地**（不然照 `.env` 走云 API，风扇不响、在烧余额）
- `… refine.py --并发文件 3`　多个文件同时在飞（单开 `--并发` 没用，池子填不满）；★ 并发文件时**索引锁**必须在（三层是读全部-改-写全部，交叉会静默丢概述）
- `… refine.py --安静`　没活干不出声（cron 用）；`--忽略停机闸门`　临时忽略 `state/停机`

**备注**：cron 那条长这样（`flock -n` 防重叠，一分钟一次）：
`* * * * * cd "<项目根>" && flock -n /tmp/collaplex-refine.lock ./.venv/bin/python skill/rag/scripts/refine.py --安静 >> logs/refine.log 2>&1`
日志固定落 `logs/refine.log`（设置页「日志 · 清洗」读的就是它）。**挂/恢复 cron 前先探一次模型**（`:8790/health` 要 200），模型不在就整轮空跑。
