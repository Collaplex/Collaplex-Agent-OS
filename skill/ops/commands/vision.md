# 看图 · 只把看到的写成字

**用途**：图上写的字（截图 / 扫描件 / 验证码）、图里画的东西（图表 / 照片 / 版式）—— 只有"眼睛"能办。主路走云端视觉模型，不成自动兜底本地 `qwen3-vl-8b`。

**用法**
- `./.venv/bin/python skill/vision/main.py 看图 <图片路径>`
- `… skill/vision/main.py 状态`　两条路各通不通 + 本轮还剩几次；★ `--真读` 能证明本地是不是真能读图
- `… skill/vision/main.py find "看图"`　查看图命令库（2 条）

**备注**
- ★ **本地那路必须带 `--mmproj --no-mmproj-offload`**：不带视觉塔，主模型只认文字，视觉请求一律回 `image input is not supported` —— 那样"本地兜底"是条假兜底；显存账要算上 mmproj。
- ★ "端点答话 ≠ 能读图"：判本地能不能读图要用 `状态 --真读` 真发一发，别看端口在听就下结论。
- 规矩：**只在要用的时候看一眼** —— 不预读、不批量读、不顺手读；**图不寄存**（不留库、不进会话历史）；两条路都不通就照实说，绝不编内容。
- 一次请求一张图（单轮闸限制次数），批量看图要按闸的节奏来。
- ★ **它不是改图的工具**：调色 / 修图 / 裁剪 / 改分辨率 / 剪视频都不归它 —— 它只把"图里有什么"写成字。
