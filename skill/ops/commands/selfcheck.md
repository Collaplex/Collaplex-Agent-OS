# 自检 · 30 项

**用途**：从图标、配置、模型接口、依赖、库、代码、结构到定时，一项一行。全过可以直接进主程序。

**用法**
- `./selfcheck.py`　跑完全过就 `execv` 换成 `main.py`（不另起一层进程）
- `./selfcheck.py --只查`　只体检不拉起；`collaplex-agent 自检` 就是这个
- 退出码：有报错 1、全好 0 —— 能挂到别处当守门
- ★ 从别的脚本调它、或 stdin 不是终端时**只查不拉**（免得守门变成捣乱）

**输出五列**：`时间 | 信息 | 等级 | 事件 | 结果`
- 信息 = 哪一块（配置 / 模型 / 依赖 / 库 / 代码 / 结构 / 定时）
- 等级 = 信息 / 警告 / 错误（警告也算正确）
- 结果 = 正确 / 报错

**备注**
- ★ **同类"读不到 / 打不开"报三条以上 = 有服务没起**：先查启动链缺哪一站（PG / 主模型 / 向量），别去查数据。
- 干净机器上这几条**属于正常**：缺 `DEEPSEEK_*` / `MIMO_*`（外援按需填）、缺 `carve`（file skill 的外部工具）、二层三层库读不到（库还空着）。
- ★ 自检里有两条**结构**判据会在加 skill 之后咬人：skill 索引跟目录对得上、命令库索引跟 `commands/*.md` 对得上 —— 都要重扫索引（见「加新 skill」那条）。
