# 外援（outsource）

## 任务目标

本地这支小模型（Qwen3-VL-8B 这类 8~9B）在**写代码、长链推理**上会卡住 ——
不是不会说话，是真推不动。这个件把卡住的那件活**交给云端强模型**做，
拿回**能直接用的产出**（完整代码 / 完整推导），而不是拿回一段"思路"。

★ 这个件**会花钱**：默认关着；开了也受每日预算和次数约束；每一笔都落盘记账。

## 触发条件

**该摇人**：
- 子 agent 的判定里出现 `wanted`（手头缺这个能力）或 `broken`（判定那步坏了，拿不准）
- 要写**成段、要能跑**的代码，而本机小模型写出来跑不通 / 写不全
- **多步数值推理 / 长链推导**，本机小模型绕圈、前后不一致
- 用户明确授权"这题不行就去问"

**不该摇**（本地就够，摇了是白花钱）：
- 查资料、读文件、看机器状态 —— 那是 rag / file / linux 的活
- 翻译、改写、总结、格式转换
- 闲聊、一句话能答的事实问题

## 怎么用

```bash
# 干一件活（默认家 = DeepSeek）
.venv/bin/python skill/outsource/main.py ask "把这段 Python 改成 asyncio 并发版：<贴代码>"

# 带上子 agent 的判定原话（由程序拼进任务，别自己转述）
.venv/bin/python skill/outsource/main.py ask "<任务>" --声明 "缺：多步比例推理"

# 看开关 / 今天花了几毛 / 凭据在不在
.venv/bin/python skill/outsource/main.py status
```

## 输出

- **stdout**：头部一行（家 / 模型 / 用量 / 估算金额）+ 产出原文，**不截断**
- **落盘** `logs/outsource/<时间戳>-<家>.md`：产出 + 用量 + 金额 + 任务原文
- **记账** `logs/outsource/用量.jsonl`：一行一次调用
- **退出码**：0 成功 / 1 失败（拿不到内容）/ 2 没调（开关关着或到预算）

## 边界与错误处理

| 情况 | 表现 | 怎么处理 |
|---|---|---|
| 开关关着 | 打印「这次不调外援: 外援开关关着」，退出码 2 | 改 `resources/outsource.json` 的 `开关`，或临时加 `--强制` |
| 到日预算 / 次数上限 | 同上，退出码 2 | 等明天。别绕（预算是钱包） |
| 凭据缺失 | 「外援失败: 找不到凭据 XXX_API_KEY」，退出码 1 | 补 `.env`；**不要把值贴出来** |
| 回来了但是空的 | 标失败 + 提示「多半被 token 上限吃光」，退出码 1 | **绝不静默当成功**；调 `max_tokens` 后重试 |
| 单次超过单次上限 | 照常返回，多打一行「提醒」 | 只是提醒，不拦 |

## 注意事项

1. **判定归程序**：外援的产出行不行 —— 主 agent 自己判 → 程序判（空答/报错/超时）→ 子 agent 兜底。
   这一件负责程序那层，**绝不把"拿不到内容"记成成功**。
2. **任务由程序拼**：`--声明` 是子 agent 的原话，程序直接拼；不让模型转述（转述丢信息还多花钱）。
3. **凭据永不落地**：key 只从 `.env` / `~/.hermes/.env` 读，产出和日志里都不写。
4. **别拿它追质量上限**：它是"卡住了摇人"，不是"每题都问一遍" —— 那是 mtp（交叉验证）的活。
