# 你负责去外面查 —— 回来只交原文片段和链接

这个 skill 管的是**外面的事**：网上某个页上到底写了什么、某个网址通不通。

**你只做两件**：把页面**取回来**，把**原文片段 + 链接**交出去。
**不总结、不复述、不改写、不推理** —— 摘要要由看结果的人下判断，不是你。

## 红线：只回原文

- 交出去的是**页面上真实存在的句子**（原样，一个字不改）+ 它的链接
- **不许**把几段揉成一段"大意"；**不许**替页面下结论；**不许**在结果里加"这说明…""总之…"
- 页面里没有的东西**不许**写；取不到就照实说取不到，把具体报错带回来
- 链接必须是真地址（`http` 开头），不是 bing 的跳转壳

## 干活四步

**第零步 · 先看热库**（省一次出网）—— 前面搜过、取过的东西就在这儿，别急着再打一遍网：

<调用>.venv/bin/python skill/search/main.py 热库 "要查的事, 用你自己的话说"</调用>

热库里全是**搜过或取过的原文片段**（结果条目 + 页面切片）。查到就直接用，这步不出网、不扣次数。

**第一步 · 搜** —— 热库里没有，再拿候选页：

<调用>.venv/bin/python skill/search/main.py 搜 "要查的东西, 用你自己的话说"</调用>

<调用>.venv/bin/python skill/search/main.py 搜 "机器学习 教程" --pages 2</调用>

输出是若干条（标题 / 链接 / 摘要 / 来源），末尾有 `含核心词「…」的 NN%` —— **这个百分比是给你判断用的**：
低于 30% 说明两站都在给泛结果，换更具体的词再搜一次（或看结果里的 `[退回核心词…]` 标记）。
默认 **bing + 百度** 一起打再跨站去重（同一地址只留一条，来源标成 `bing+百度`）；某站挂了会在 stderr 打
`[有站没成] …`，另一站的结果照给。搜到的**自动落热库**，并扣一次数。

**第二步 · 取** —— 把选中那条真取回来（**用真浏览器**，有些站拦直抓）：

<调用>.venv/bin/python skill/search/main.py 取 "https://某条结果的链接"</调用>

回的是 JSON：`status` 状态码、`title` 标题、`text_chars` 正文长度、`html_path` 落盘路径、
`shot_path` 截图路径、`err_kind` / `err_msg` 出错原因。

**只想看这页长什么样**（排版 / 图片 / 图表 / 是不是挂了）、**不要正文**，就走 `截图` —— 它回得更干脆：

<调用>.venv/bin/python skill/search/main.py 截图 "https://某条结果的链接"</调用>

回 JSON 只关心一件事：`shot_path`（图在哪）。**截到图就算成** —— 页面没正文也算成，图就是结果。

**第三步 · 正文** —— 想要干净正文就把上一步的 `html_path` 喂进去：

<调用>.venv/bin/python skill/search/main.py 正文 skill/search/cache/pages/xxxxxxxx.html --max 8</调用>

段落是**原文**（去壳留肉：扔掉脚本/样式/导航/页脚，段够长就留）。要回答问题时贴其中最相关的几段。
想让它**以后还能回查**，加上 `--save --url <这条的链接>`（会按 rag 的算法切片落热库，截图一起记）：

<调用>.venv/bin/python skill/search/main.py 正文 skill/search/cache/pages/xxxxxxxx.html --save --url "https://…" --query "你搜的词"</调用>

## 三道闸

1. **命令跑通了没有** —— 看退出码：
   - `[取不到] …` → 原因写在后面，照实回报
   - 退出码 2 → 动作名写错了，回第一步查命令库

2. **报错怎么报**（四类，各有各的说法，别混成一团）：

   | `err_kind` | 意思 | 你该怎么说 |
   |---|---|---|
   | `站点不存在` | 域名解析不了 | 「这个域名不存在」+ 域名 |
   | `响应超时` | 连上了没回话 | 「响应超时」+ 网址 |
   | `HTTPS 错误` | 证书有问题 | 「HTTPS 证书错误」+ 网址 |
   | `具体报错` | 404 / 403 / 站点拒绝 | **照抄**里面的码（如 `HTTP 404`） |
   | `空页面` | 取到了但几乎没有正文 | 只说「页面没有正文」，把 `shot_path` 给出去 —— **要真看这页长什么样，那是 `vision` 的活**（`skill/vision/main.py 看图 <shot_path>`） |
   | — | 搜索站被挡成验证页 | 照实说「百度被挡成验证页了，歇一会儿再试」——**别当成"没搜到"** |

3. **结果对路吗** —— 拿回来的东西回头对一遍交办的问题：
   - 问"某页写了什么" → 要**那个页的原文片段**，不是搜索结果里的摘要
   - 问"某某是不是真的" → 要**原文那句话 + 链接**，让人自己看
   - 问"这个站还在吗" → 要**状态码或具体报错**，不许猜

## 体积闸（别一次搜出格）

三个档，都写在 `resources/store.json` —— **撞上了是拦你，不是坏了**：

- **单页 5MB**：取回来的 HTML 超了就截断（浏览器与直抓都封着）
- **单次 20MB**：一条命令（跨站跨页累加）取到顶就**停手**，stderr 会打 `[体积闸] …`
  还剩 20MB 以上没取完，说明你 `--pages` 开太大了 —— 改成更具体的词，别硬加页数
- **落盘 2GB LRU**：`cache/pages` + `cache/shots` 超了**从最老的删**（删截图时顺手抹掉库里的引用）

## 结果会落库（热库 / 冷库）

- `搜` 到的条目、`正文 --save` 的页面切片都进 **热库 `search_hot`**：**检索只查这张**，热窗口 24 小时
- 过了热窗口自动**沉到冷库 `search_corpus`**（留 90 天 / 2GB 封顶）；冷库不参与检索，只做留存复用
- **去重**：同一条（同一地址 + 同一段原文）只留一条；再搜到只刷新使用时间，不重复入库
- 每行都记 **`status`**（这页取回来的 HTTP 码）：serp 行是结果页的码，正文行从 `取` 的输出抄
  （`正文 --save --status N`）；`0` = 当时没拿到
- **截图跟 TTL 一起清**：页面块落库时记了截图路径，冷库那行到点被删时那张 jpg 一起删
- 平时不用管（每次落库都顺手下沉与清理）；想看现状或手动跑就用 `语料` / `过期` / `清理`

## 什么不该用这个 skill

- **项目里的东西**（代码怎么写的、配置在哪、之前记过什么）→ 那是 `rag`，不用上网
- **算数** → 那是 `math`
- **查这台机器**（磁盘/内存/进程/端口）→ 那是 `linux`
- **网页截图以外的作图** → 那是 `math` 的 `plot`
- **图上画的东西 / 截图里到底写了什么** → 那是 `vision`（`skill/vision/main.py 看图 <图的路径>`）——
  这里只管**页面上写的字**；图交给它，它看完只回文字（图不寄存）

## 红线（这几样别做）

- **不总结**：上面那条，最要紧。原文片段 + 链接，完事
- **不编**：取不到就说取不到，不许拿搜索结果里的摘要冒充页内原文
- **不装作取过**：没跑命令就说没跑
- **不刷量**：一轮里的命令条数有上限（防你发疯），超了会被拦；一次别发起超过 100 条
