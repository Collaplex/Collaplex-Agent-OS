# 查询语法 · 搜索算子哪家认（本机实测，2026-10-10）

**用途**：要「只在这种站里找」/「只要 PDF」/「只要标题里有这个词」/「别出现那个词」的时候，
先看这张表决定**往哪个站打**、以及哪个算子是白加。

**用法**：`.venv/bin/python skill/search/main.py 搜 "<算子><词> <别的词>" --site baidu|bing`

**实测表**（本机两条路上逐个打，看**回来的链接**符不符合算子；每格都是当次那一打的真实命中）

| 算子写法 | cn.bing（默认） | 百度（`--site baidu`） |
|---|---|---|
| `site:github.com playwright` | ✗ **整条忽略**（0/6 条含 github.com） | ✓ 认（6/6 条都在 github.com） |
| `filetype:pdf 高等数学 教材` | ✗ **整条忽略**（0/6 条是 .pdf） | ✓ 认（5/6 条是 .pdf） |
| `intitle:爬虫 python 教程` | ✓ 认（6/6 条标题含「爬虫」） | ✓ 认（7/7 条含「爬虫」） |
| `"碰撞搜索引擎" 原理`（定串） | ✗ 不硬保（0/6 条含整串） | ✗ 不硬保（0/7 条含整串） |
| `深度学习 -综述`（排除） | ✓ 认（0/6 条仍出现「综述」） | ✓ 认（0/9 条仍出现「综述」） |

**照着用**：

- 要 `site:` / `filetype:` → **必须 `--site baidu`**。打 cn.bing 是白加（它把算子当普通词，还会
  顺带把结果带偏成泛结果）。
- `intitle:`、`-` 排除 → 两家都认，随便挑（默认 `both` 两家一起打也行）。
- `"定串"` → **两家都不硬保**：真没有这个短语（比如自己造的名词）它照样回一屏泛结果。
  所以「回来看见有结果」≠「这词存在」—— 要判它真有没有，数一数标题/摘要里含不含整串
  （这次实测 0/6、0/7 就是这么数出来的）。
- 要「这家单位/这个词到底存不存在」→ 先 `热库 "<词>"` 看搜过没有（省一次出网）。

**备注**：①程序会从查询里挑一个「核心词」自检**对题率**（挑最长的中文词），挑之前
**先把算子壳剥掉**：`site:github.com` 这种整条丢、`intitle:爬虫` 留「爬虫」、`-综述` 丢掉。
不剥的话对题率会**误报 0.0%**（百度那条明明 6/6 全中），而默认的「不对题就退回核心词重查」
还会拿着 `site:github.com` 这个串去重查 —— 回来一屏无关结果（2026-10-10 修）。
②对题率 = 这批结果里有多少条**真含核心词**；低于 30% 就是这站在灌泛结果。
但 PDF 站/文库站的标题常常写的是书名（不含你查的那些词），这时 0% 是**真的**不对题，
不是误报（实测 `filetype:pdf 高等数学 教材` 百度回来的是《数学分析》《线性代数》→ 0.0%）。
③算子跟别的词之间要**留空格**（`site:github.com 爬虫` 对，`site:github.com爬虫` 会被当一个词）。
