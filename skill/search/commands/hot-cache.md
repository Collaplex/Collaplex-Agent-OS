# 热库 · 只在搜过的东西里回查（省一次出网）

**用途**：这个问题前面搜过、或者刚才取过的页面里就有 —— 直接回查，不用再打一遍网。
**只查热的**（默认 24 小时窗口内的），冷库（沉下去的老语料）不参与检索。

**用法**：`.venv/bin/python skill/search/main.py 热库 "<想找的话>" [-n N] [--kind serp|page] [--json]`

**选项**
- `-n N` 要几条（默认 10）
- `--kind serp` 只要搜索结果条目 / `--kind page` 只要取回来的页面块
- `--json` 出 JSON

**示例**
- `热库 "这个学校有几个校区"`　命中摘要里写着"梅山、镜湖两个校区"的那条（★ 语义命中，不是字面匹配）
- `热库 "学校有多少在校生" --kind page -n 2`　只要页面正文的切片

**输出每条**：相似度 / `[来源 / kind]` / 标题 / 链接 / 片段（`serp` 给摘要，`page` 给那块原文）

**备注**
- 库里有什么：`搜` 进去的结果条目（kind=serp）+ `正文 --save` 进去的页面切片（kind=page）
- 来源只是**一列**（bing / 百度 / 直连）：热库是共用一份，不按来源分家
- 命中过的行会记一次使用次数（`语料` 里能看到总量）；这不算出网，**不扣单轮次数**
- 查不到就先 `搜` 一遍；同一条再搜到不会重复入库，只刷新使用时间
