# 截图 · 真浏览器渲染后只截一张整页图

**用途**：要**看一眼这页长什么样**（排版 / 图片 / 图表 / 验证码 / 是不是挂了），
不需要正文时走这条。和 `取` 是同一条渲染路（系统 Chrome 走 CDP），**只是不回正文，只回图**。

**用法**：`.venv/bin/python skill/search/main.py 截图 "<url>" [--shot 路径]`

**选项**
- `--shot 路径` 截图存哪（默认 `skill/search/cache/shots/<url摘要>.jpg`，与 `取` 同一个命名指纹）

**输出**（JSON）

| 字段 | 意思 |
|---|---|
| `ok` | **截到图就算成**（页面没正文也算成 —— 图就是结果） |
| `status` | HTTP 状态码（拿不到就是 `null`） |
| `title` | 页面标题 |
| `shot_path` | 整页截图（1440 宽，按内容高度，最多 8000px） |
| `final_url` | 跟完跳转之后的地址 |
| `err_kind` / `err_msg` | 截图都没截到时的出错口径（见 `fetch.md` 的四类） |
| `ms` | 花了多久（毫秒） |

**和 `取` 的分工**

| | 截图 | 取 |
|---|---|---|
| 回什么 | 只有图路径 | 图 + `html_path` + `text_chars` + 正文长度 |
| `ok` 判据 | 截到图 = 成（空页面也算成） | 取到且有正文才算成 |
| 什么时候用 | 「这页长啥样」「是不是挂了」「图里写了什么」 | 「这页写了什么」要正文时 |

**示例**
- `截图 "https://www.zjipc.com/"`　200 / 图 428KB / 标题「浙江工业职业技术学院」
- `截图 "https://www.python.org/" --shot /tmp/py.jpg`

**备注**：①截图落在 `skill/search/cache/shots/`（不进 git），**跟热库 TTL 一起清**（见架构 §2）。
②落盘总量有 2GB 上限（LRU，最老的先删）；真要留住某张图，自己拷走。
③浏览器是**常驻**的，第一次用会冷启（2~4 秒），之后每页 3~4 秒。
