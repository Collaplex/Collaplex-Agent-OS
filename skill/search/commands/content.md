# 正文 · HTML 去壳留肉成正文段落

**用途**：把取回来的 html 变成**干净的正文段落**（扔掉脚本 / 样式 / 导航 / 页头页脚 / 侧栏 / 弹层）。
**不做正文识别算法**（那玩意容易误伤）—— 块级标签断段，**段够长就留**，太短的（导航词、按钮字）扔掉。

**用法**：`.venv/bin/python skill/search/main.py 正文 "<html文件>" [--min N] [--max N] [--json]`
（给 `-` 就从标准输入读）

**选项**
- `--min N` 段至少几个字（默认 10）；**想滤掉导航词就调到 40** —— 实测百科那页：默认切 398 段，`--min 40` 剩 127 段且开头就是正文
- `--max N` 最多打几段（默认全给）
- `--json` 出 JSON：`{"title", "count", "chars", "shown", "paragraphs": [...]}`
  （`count` / `chars` 是**全部**段的数与字数，`shown` 是这次真打了几段）

**示例**
- `正文 skill/search/cache/pages/97d042a18737c4a8.html --max 5`
- `正文 <百科那页.html> --min 40 --max 3`　直接出「浙江工业职业技术学院（…），位于浙江省绍兴市…」这种原文
- `正文 - --json < 存下来的.html`

**输出**
```
标题: 浙江工业职业技术学院_百度百科    正文 127 段 / 11771 字 （这里打了前 3 段 / 582 字）

[1] 浙江工业职业技术学院（Zhejiang Industry Polytechnic College），位于浙江省绍兴市……
[2] 学校创建于1979年的浙江省矿冶技工学校；1985年与浙江省冶金地质勘探公司职工学校合并……
```

**备注**：①段落是**原文**，一个字都不改写 —— 摘要是要交出去的东西，得让人自己看原文。
②段落**按页面顺序**，开头常有一串导航词（「网页新闻贴吧知道…」）—— 那不算错，用 `--min 40` 滤掉即可。
③同一段在页面里重复出现（版权行 / 导航）只留一次。
④单段上限 4000 字，超了硬切。
⑤解析遇到脏 HTML 不抛异常（返回已经收到的部分），所以"段数为 0"是有意义的信号：
该页可能真是空壳（这时只回截图，见 `取` 的 `空页面`）。
