# 搜 · 去 bing 与百度拿结果（标题 / 链接 / 摘要 / 来源）

**用途**：想要"网上有哪些页讲这个"的时候走这条。拿回来的是候选页清单（标题 / 链接 / 摘要 / 来源），
不是页内原文 —— 要看原文得再用 `取` 把选中的那条抓回来。

**用法**：`.venv/bin/python skill/search/main.py 搜 "<查询词>" [--pages N] [--site both|bing|baidu] [--engine auto|browser|http] [--no-fallback] [--no-save] [--no-gate] [--json]`

**选项**
- `--pages N` 每站打几页（每页 10 条，默认 1）
- `--site both` 打哪个站：`both` 两家一起（默认）/ `bing` / `baidu`
- `--engine auto` 取页路：`auto` 按各站自己的偏好（默认）/ `browser` 真浏览器 / `http` 直抓
- `--no-fallback` 不对题也不退回核心词重查
- `--no-save` 这次不落热库（默认落）
- `--no-gate` 不过单轮次数闸（默认过，一次算 1 次）
- `--json` 出 JSON（给程序吃；默认给人看）

**示例**
- `搜 "浙江工业职业技术学院 绍兴"`　17 条（百度 7 + bing 10），对题率 100%
- `搜 "机器学习 教程"`　9/10 条对题
- `搜 "绍兴 高职院校 排名" --site bing`　百度被挡时只走 bing
- `搜 "collaplex 搜索引擎" --json`

**每站的取页路不一样（实测出来的，别改）**
- **bing**：真浏览器优先（防爬虫识别），挂了回落直抓 —— 两条路都能拿到结果
- **百度**：**只能直抓** —— 真浏览器打百度拿到的是空页面（正文 52 字），HTTP 直抓 200 / 988KB / 7~8 条真结果

**备注**：①输出末尾的 `含核心词「…」的 NN%` 是**对题率**，低于 30% 就是这俩站在给泛结果。
②**cn.bing.com 对长中文机构名的分词很差**：给「浙江工业职业技术学院 绍兴」它会退化成按「浙江」泛搜 ——
所以本命令会**按站各退各的**（最长的中文词），谁对题用谁，退回时结果里标 `[退回核心词「…」重查的结果]`。
要关掉就加 `--no-fallback`。★ 按站退很重要：放一起判的话 bing 那堆泛结果会把整体拉低（实测 100% → 41%）。
③URL 参数只带 `q` 与 `count`：实测 `ensearch=1` 会让结果变成完全无关的（AutoCAD 那种），别加。
④`www.bing.com` 的结果比 `cn.bing.com` 差得多，所以默认走 cn。
⑤**百度会挡**：连打几次它会换成「百度安全验证」页 —— 这时命令会明说"被挡成验证页了"，
不会混成"没搜到"；隔一会儿再试。两站一起打时某站挂了会在 stderr 打 `[有站没成] …`，另一站的结果照给。
⑥**搜到的会自动落热库**（去重：同一条只刷新使用次数），并在 stderr 打 `[落库] 热库: 新增 N / 复用 M`。
想回查落过的东西用 `热库 "…"`。
