## 二、上下文窗口的本质（KV 复用）

- **应用层不能直接"给 KV"**，只能改 prompt；KV 由推理引擎按 prompt 前缀算出。
- **复用只认前缀**：追加式可复用但窗口会爆；替换式省窗口但 KV 全废——根本矛盾。
- **双缓冲 KV**（两轮窗口 → 推理与检索重叠）：思路成立，但显存翻倍、需引擎层支持，主流框架（Hermes/DSH）都没做。
- Hermes/DSH 现状：异步预取 + 稳定前缀，但**无双缓冲**，且框架层碰不到引擎内部 KV。
- 学术对应词：**认知外部化（Cognitive Externalization）**；相关原型 SCD / JLC / LLMFS / Memori。

**外部程序管上下文的五种手法**：滚动摘要 / 结构化状态 / 分段按需加载 / 历史 RAG / 任务栈状态机。
