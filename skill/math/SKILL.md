# 你负责算数 —— 每个数都得是 Python 真算出来的

要的是一个**确定、可复核的数**。这个 skill 存在的唯一目的，就是不让模型自己硬算。

## 怎么调（按平台，先看这一节）

入口就一个，**Windows 装包里走编译版**（`math.exe`，源码不外露）：

| 平台 | 写法 |
| --- | --- |
| Windows（装包默认） | `skill\math\math.exe <动作> [参数...]` |
| Linux / 源码版 | `.venv/bin/python skill/math/main.py <动作> [参数...]` |

★ **反斜杠**：上面 `skill\math\math.exe` 里的 `\` 在 **md / 命令行里就是一个反斜杠**；
要是往 JSON、Python 字符串、`.bat` 里塞这条命令，**该转义的地方必须写 `\\`** —— 三种地方规则不同，别互相照抄。

★ **编译版能用的动作**：`calc` `num` `solve` `linalg` `poly` `calculus` `stats` `prob`
（算）＋ `money` `units` `plot` `date`（换算/出图/日期）。
`find` / `index` 要连 rag 那套模块（embed/search/store → psycopg），**编译版不带它们** ——
那种活走源码版的 `.py` 入口，或者由程序侧自己查好命令库贴给你。

## 红线：不许硬算（这一条最要紧）

- 只要结论里会出现**数字的运算结果**，就先写命令、拿命令的输出说话 —— 四则、百分比、乘方开方、大数、统计、概率、方程、矩阵、单位换算、日期天数，一个都别例外
- **不许**先在心里推、再挑一个数写出来；**不许**把"差不多是多少"的估计当答案；**不许**凭记忆报常见值（`2^10`、`170!`、`1/3` 的小数、汇率、月供）
- 命令的输出**照抄**：别四舍五入成好看的整数，别把 `精确` 写成 `近似`（或反过来），别把分数 `3/7` 自己化成小数
- 命令说"算不了"（退出码 1）就如实回报**原因**，不许改口自己算一个补上
- 位数不够就用 `--位数 N` 重跑一次，**不要**拿 10 位去猜后面的位

## 干活三步

**第一步 · 命令库** —— 条目**已经由程序查好、贴在这条任务的末尾了**（"## 命令库条目"那段），
先读它们、照它写命令：用法 / 选项 / 示例 / 备注都在里面。

万一条目都不对路，自己再查一次：

<调用>skill\math\math.exe find "要算的活, 用你自己的话说" -n 3</调用>

命令库里有这些（都走**同一个入口**，按动作名分；入口写法见上面「怎么调」）：


**第二步 · 真跑** —— **必须真把命令写出来**：

<调用>skill\math\math.exe calc "1/3+1/6" --位数 20</调用>

★ **只说明打算算什么、不写出命令 = 白说**：程序只认写出来的命令。像"我来算一下"、"大概是 0.33"这种都不算数。
一轮里给好几条也会挨个跑，输出逐条贴回给你。

**第三步 · 汇总**：把命令的**关键行**贴回去（结果 + 成色 + 必要的中间行），一句话给结论。
**别复述表达式**，也别把整段输出抄回（三五行够）。图上给文件路径，不要说"画好了"却不给路径。

## 两道闸

1. **命令跑通了没有** —— 看退出码：
   - 退出码 1 + `[算不了] …` → 原因会写在后面（除数为 0 / 负数开方 / 区间内没根 / 单位跨类…），**照实回报**
   - 退出码 2 → 动作名或用法写错了，回第一步重查命令库（最多重查一次）
   - `no such file or directory` → 路径写错了：入口是 `skill\math\math.exe`（源码版 `skill/math/main.py`），命令一律**从项目根**跑

2. **结果对不对路** —— 拿真输出回头对一遍交办的活，**这类问法该有什么就必须有什么**：
   - 问"等于多少 / 多少" → 要**那个数**，还要带上 `精确/近似`
   - 问"精确值 / 要多少位" → 用 `--位数 N` 把位数真给到，别用默认 10 位糊弄
   - 问"哪个更大 / 差多少" → **两个数都算出来**再比，不许只算一个
   - 问"图上什么样 / 画个图" → 要**文件路径 + 关键范围**（y 范围/极值）
   - 问"日期 / 还有多少天" → 要**具体天数**（要工作日就一起给）

## 什么不该用这个 skill

- **查资料**（某年人口、某公司规模）→ 那是检索的活，这个 skill 只算不查
- **看这台机器的状态**（磁盘/内存/进程）→ 那是 linux skill
- **读写代码文件** → 那是 file skill
- **纯核对数字**（把两串数对一遍看有没有抄错）→ 直接比，不用算

## 红线（这几样别做）

- **不许硬算**：上面那条，最重要
- **不许改数**：命令给 `3/7` 就报 `3/7`，要小数就用命令再要一次小数
- **不撒谎**：没跑就说没跑；命令报错就把错误照贴
- **不许改没让算的东西**：声明里要算什么就算什么，`plot` 落图默认落在 `skill/math/logs/`，别往项目别处写
