# poly · 多项式

**用途**：多项式运算：求值、求根、加减乘除（带余）、求导、积分。系数用 JSON 数组写，**从高次到低次**：`[1,0,-4]` 就是 x²-4。

**用法**：`.venv/bin/python skill/math/main.py poly <子动作> "<系数>" ["<系数2>"/<x>]`

**子动作**
- `求值 "[1,0,-4]" 3`　代入求值（精确）
- `根 "[1,0,-4]"`　全部根（含复根，数值）
- `加` / `减` / `乘`　两个多项式
- `除 "[1,0,-4]" "[1,-2]"`　商 + 余式（带校验行）
- `导数 "[1,2,3]" [阶数]`　降幂导数
- `积分 "[1,2,3]"`　原函数（末尾 + C）

**示例**
- `poly 乘 "[1,1]" "[1,-1]"`　→ x^2 - 1
- `poly 除 "[1,0,-4]" "[1,-2]"`　→ 商 x + 2，余 0
- `poly 求值 "[1,0,-4]" 3`　→ 5
- `poly 导数 "[1,0,-4]"`　→ 2x

**备注**：①系数写分数也行（`"1/2"`），加减乘除和导积都按精确分数算。②`根` 是数值解法（numpy），带 -0j 这种极小的虚部会照实给出。③零多项式、除式为 0 会直接报错。
