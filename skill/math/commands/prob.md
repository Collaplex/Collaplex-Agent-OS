# prob · 概率分布

**用途**：常见分布上的概率：二项、正态、泊松、几何。二项/几何给**精确分数**，正态走标准正态 erf，泊松走高精度 Decimal。

**用法**：`.venv/bin/python skill/math/main.py prob <子动作> ...`

**子动作**
- `二项 <n> <p> <k>`　恰好 k 次 / 至多 k 次 / 至少 k 次 + 期望方差
- `正态 <均值> <标准差> <x>`　P(X<=x)、P(X>=x)、标准化 z
- `正态 <均值> <标准差> 0 --区间 a b`　给区间概率（第三个参数占位，可写 0）
- `泊松 <λ> <k>`　P(X=k)、P(X<=k)
- `几何 <p> <k>`　第 k 次才成功的概率

**示例**
- `prob 二项 10 0.5 5`　→ 恰好 63/256、至少 319/512（精确）
- `prob 二项 20 0.05 0`　→ 至少一次约 0.6415
- `prob 正态 0 1 1.96`　→ P(X<=1.96) = 0.9750021
- `prob 泊松 3 2`　→ 0.2240418076…（20+ 位）
- `prob 几何 0.2 5`　→ 0.08192

**备注**：①p 写小数或分数都行（`0.05` 或 `1/20`），越界会报错。②二项给的是精确分数，要小数用 `--位数 N`。③正态只到双精度（erf），泊松给高精度。
