# linalg · 矩阵与线性代数

**用途**：矩阵运算：行列式、逆、转置、乘法、秩、解线性方程组、特征值。矩阵用 JSON 二维数组写。

**用法**：`.venv/bin/python skill/math/main.py linalg <子动作> "<矩阵>" ["<矩阵2>"/"<向量>"]`

**子动作**
- `行列式 "[[1,2],[3,4]]"`　要方阵
- `逆 "[[4,7],[2,6]]"`　给逆矩阵（同时报 det）
- `转置 "[[1,2,3],[4,5,6]]"`
- `乘 "A" "B"`　尺寸对不上会明说
- `秩 "..."`　秩（方阵同时给 det）
- `解 "[[2,1],[1,3]]" "[[5],[10]]"`　解 A·x=b，附最大偏差验证
- `特征值 "[[2,0],[0,3]]"`　特征值（含复根）

**示例**
- `linalg 行列式 "[[1,2],[3,4]]"`　→ -2
- `linalg 逆 "[[4,7],[2,6]]"`　→ [[0.6,-0.7],[-0.2,0.4]]
- `linalg 解 "[[2,1],[1,3]]" "[[5],[10]]"`　→ x1=1, x2=3（偏差 0）

**备注**：①矩阵是浮点算法（行业惯例）：整数结果会自动取整显示，别把 `1.9999999` 当答案手改。②一行写一篇 JSON，参数别加空格以外的分隔符。③要精确解的中小规模方程组走 `solve 线性`。
