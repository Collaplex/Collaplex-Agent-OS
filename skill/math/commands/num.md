# num · 数论与计数（分解 / 质数 / 组合 / 进制 / 位运算）

**用途**：整数上的活：分解质因数、判质数、阶乘、组合排列、斐波那契、最大公约数、进制转换、位运算。都是大数整数精确算，别手推。

**用法**：`.venv/bin/python skill/math/main.py num <子动作> ...`

**子动作**
- `分解 <整数>`　质因数分解（1e18 内；除数超 1e7 会说明"没分解完"）
- `质数 <整数>`　确定性 Miller-Rabin 判质数
- `阶乘 <n>`　n! 全量（0~100000）
- `组合 <n> <k>` / `排列 <n> <k>`　C(n,k) / P(n,k)
- `斐波那契 <项号>`　F(n)，大数
- `约 <A> <B>`　最大公约数 + 最小公倍数
- `进制 <数> [目标进制]`　同时给 2/8/16/目标进制；也可 `进制 <数> <源进制> <目标进制>`
- `位 "<表达式>"`　位运算：`& | ^ ~ << >>`，支持 `0x` `0b` 写法

**示例**
- `num 分解 360`　2^3 · 3^2 · 5
- `num 质数 1000000007`　是质数
- `num 组合 49 6`　13983816（彩票别自己乘）
- `num 进制 255`　ff / 11111111 / 377
- `num 位 "1 << 40"`　1099511627776

**备注**：①大数（阶乘、斐波那契）会同时报"共几位"。②`组合` 要求 0<=k<=n，越界直接报错。
