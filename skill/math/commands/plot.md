# plot · 出图（函数图 / 折线 / 散点 / 柱状）

**用途**：把函数或数据画成图，直接落地一个 SVG 文件（纯标准库拼的 SVG，零依赖）。想让人一眼看到趋势、形状、极值就画一张，别用文字描述曲线。

**用法**：`.venv/bin/python skill/math/main.py plot <子动作> ... [-o 文件.svg]`

**子动作**
- `函数 "<f(x)>" <起> <止> [--点 N]`　画函数（默认采 400 点，无定义处自动跳过）
- `折线 "<点集>"`　`"1,2 3,4"` 或 `[[1,2],[3,4]]`
- `散点 "<点集>"`
- `柱状 "标签=值,标签=值"`

**选项**：`-o 路径.svg` 指定存哪（默认存 `skill/math/logs/<子动作>-<时间>.svg`）；`--点 N` 采点数（2~5000）

**示例**
- `plot 函数 "sin(x)" -6.2832 6.2832`　→ 一条正弦
- `plot 函数 "x^2-4" -5 5`　→ 抛物线（含 x 轴交点）
- `plot 散点 "[[1,2],[2,3],[4,3],[5,6]]"`
- `plot 柱状 "一月=120,二月=90,三月=145"`

**备注**：①输出里会给文件路径和 y 范围 —— 把路径报回去让人看图，别口头"画好了"。②函数有间断（如 `1/x`）时会把无定义的点跳掉，图上会断。③深色皮肤：纯黑底 + 绿线，和官网一套观感。
