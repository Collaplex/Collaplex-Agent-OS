# solve · 解方程与方程组

**用途**：解方程。一元方程给数值实根（扫符号变化 + 二分），线性方程组给**精确**有理数解（高斯消元）。

**用法**
- `.venv/bin/python skill/math/main.py solve 一元 "<方程>" [--区间 A B]`
- `.venv/bin/python skill/math/main.py solve 线性 "<方程1>" "<方程2>" ...`

**选项**：`--区间 A B`　一元方程的搜索区间（默认 -100 到 100；区间外的根找不到）

**写法**
- 方程带 `=`，左边右边都认：`"x^2-2=0"`、`"x^3-6x^2+11x-6=0"`
- 隐式乘法照样通：`"2x+3y=7"`
- 线性方程组里变量用**单字母**，方程个数要等于变量个数

**示例**
- `solve 一元 "x^2-2=0" --区间 -5 5`　→ x ≈ -1.414213562 / 1.414213562
- `solve 一元 "x^2+1=0"`　→ 说明区间内没实根
- `solve 线性 "2x+3y=7" "x-y=1"`　→ x=2, y=1（精确）

**备注**：①一元只给**近似**根（扫描 + 二分），不是解析解；根重数、区间外的根都不保证。②线性方程组会先验一遍是不是真线性，二次项直接报错。③求解失败（系数矩阵奇异）会说"没有唯一解"。
