# money · 钱（占比 / 折扣 / 涨跌 / 利息 / 月供）

**用途**：跟钱有关的账：百分比占比、打折、涨跌、单利、复利（可年年追加）、等额本息月供。全程 Decimal 高精度，不用 float —— 0.1 元就是 0.1 元。

**用法**：`.venv/bin/python skill/math/main.py money <子动作> ...`

**子动作**
- `占比 <部分> <整体>`　百分比 + 倍数
- `折扣 <原价> <折数>`　按中文习惯：`8` = 八折，`8.5` = 八五折
- `涨 <原值> <百分比%>` / `跌 <原值> <百分比%>`
- `单利 <本金> <年利率%> <年数>`
- `复利 <本金> <年利率%> <年数> [--每年追加 x] [--复利次数 m]`
- `月供 <本金> <年利率%> <月数>`　等额本息 + 总还款 + 总利息

**示例**
- `money 折扣 200 8.5`　→ 现价 170，省 30
- `money 复利 10000 3.5 10 --每年追加 1000`　→ 总投入 20000，终值 25837.38…
- `money 月供 1000000 4.2 360`　→ 每月 4890.17，总利息 760461.83
- `money 占比 30 200`　→ 15%

**备注**：①利率写成"年利率的百分数"：4.2 就是 4.2%/年。②复利默认每年复利 1 次，`--复利次数 12` 是每月复利；每年追加发生在**每满一年后**。③月供是等额本息，不是等额本金。
