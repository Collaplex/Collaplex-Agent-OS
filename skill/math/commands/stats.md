# stats · 描述统计 / 相关 / 回归

**用途**：一组数看分布（均值、中位数、众数、方差、四分位），两组数看关系（皮尔逊相关、最小二乘直线）。均值方差等走精确分数，不累积浮点误差。

**用法**：`.venv/bin/python skill/math/main.py stats <子动作> "<数据>" ["<数据2>"]`

**数据写法**：`"1,2,3"`、`"1 2 3"`、`"[1,2,3]"`、`"1、2、3"` 都认。

**子动作**
- `描述 "<数据>"`　个数/和/均值/中位数/众数/极差/样本方差/样本标准差/总体方差/总体标准差/Q1/Q3/IQR
- `相关 "<x>" "<y>"`　皮尔逊 r
- `回归 "<x>" "<y>"`　y = a·x + b、R²、残差平方和

**示例**
- `stats 描述 "2,4,4,4,5,5,7,9"`　→ 均值 5、总体方差 4、Q1=4
- `stats 相关 "1,2,3,4" "2,4,6,8"`　→ r = 1
- `stats 回归 "1,2,3,4" "2,4,6,9"`　→ y = 2.3x - 0.5，R² = 0.9888

**备注**：①`相关`/`回归` 两组数据必须一样长，至少 2 个点。②r 只量**线性**关系，接近 0 不等于没关系。③方差默认给样本和总体两套，报数时说清用的是哪个。
