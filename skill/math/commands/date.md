# date · 日期与天数

**用途**：日期加减、两个日子差多少天（含工作日）、看周几/第几周。日期写 `2026-10-07`（`/`、`.`、`年月日`、`20261007` 也认；`今天` `明天` `昨天` 直接写）。

**用法**：`.venv/bin/python skill/math/main.py date <子动作> ...`

**子动作**
- `差 <日期1> <日期2>`　相差天数 + 周数 + 工作日（不含周末）
- `加 <日期> <如 30天 / 2周 / 3月 / 1年>`　可带负号往回推
- `周几 <日期>`　星期、今年第几天、ISO 第几周、是否闰年
- `今天`　今天 + 星期 + 第几天/第几周

**示例**
- `date 差 2026-01-01 2026-10-07`　→ 279 天，工作日 199 天
- `date 加 2026-10-07 30天`　→ 2026-11-06（周五）
- `date 加 2026-01-31 1月`　→ 2026-02-28（超出当月就压到月末）
- `date 周几 2026-10-07`　→ 周三，第 280 天

**备注**：①`差` 只是日子相减，不含两端当天的小时数。②工作日只排周六周日，不含法定节假日。③按月推算遇到 31 号 → 2 月会自动落到月末，这是刻意的，别当 bug。
