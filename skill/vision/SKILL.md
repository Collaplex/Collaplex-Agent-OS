# 你负责看一眼图 —— 只把看到的写成字交出去

有几件事只有**眼睛**能办：图上的字（截图 / 扫描件 / 验证码）、图里画的东西（图表 / 照片 / 版式）。
这个 skill 就是把那一眼交出去，拿回**文字**。

## 三条定调（比参数要紧）

1. **只在要用的时候看一眼** —— 不预读、不批量读、不因为"顺手"去读。
   `search` 取回来一张截图，**不等于**你要去看它；要不要看，由当时那件事决定。
2. **图不寄存** —— 那次请求发出去，回来的是文字。图不进会话、不进任何库、不落第二份。
   你别在回答里贴图、也别把图片路径当成"待会儿还要用"的东西反复引用。
3. **只报图上真有的** —— 看不清就说"看不清"，图上没有就说"没有"。**不许猜、不许补、不许圆**。

## 触发条件

**该看**：
- 手里有一张图（`search` 的 `shot_path`、用户给的路径），而那件事的答案**只可能在图上**
  （空壳页只回了截图、验证码、图表读数、版面是不是挂了、扫描件上的字）
- `search` 报 `空页面`（"正文只有 98 字"）—— 正文没东西，那就看一眼图

**不该看**（图上没有你要的东西，看了是白花钱）：
- 答案在**页面的字**里 → 那是 `search` 的 `正文`，别去看截图
- 答案在**自家项目**里 → 那是 `rag`
- 答案在**算数**里 → 那是 `math`
- 只是"想确认一下"却没有具体问题 —— 别发

## 怎么用

```bash
# 看一眼（主路云端；不成自动兜底本地）
.venv/bin/python skill/vision/main.py 看图 skill/search/cache/shots/xxxxxxxx.jpg

# 带上你真正想问的（比默认问句准得多）
.venv/bin/python skill/vision/main.py 看图 某图.png --问 "这张图的标题是什么？"

# 出 JSON（给程序读）
.venv/bin/python skill/vision/main.py 看图 某图.png --问 "图里有几个柱子？" --json

# 两条路各通不通 / 本轮还剩几次（--真读 还能证明本地能不能读图）
.venv/bin/python skill/vision/main.py 状态 --真读
```

**一次一张。** 要看好几张就发几条命令 —— "看一眼"就是一眼。

## 输出

- **stdout**：一行头（`[看图] 云端 · mimo-v2.6-flash · 3.1s · 本轮还剩 19 次`）＋ 它看到的正文
- **`--json`**：`{"ok": true, "路": "云端", "模型": "...", "文字": "...", "产出": "logs/vision/..."}`
- **落盘** `logs/vision/`：一行账（`调用.jsonl`：谁读的 / 耗时 / 图多大）＋ 一份产出 `.md`
- **退出码**：`0` 成 / `1` 没成（图的问题，或两条路都不通）/ `2` 被闸拦（这一轮看太多张了）

## 边界与错误处理

| 情况 | 表现 | 你该怎么回报 |
|---|---|---|
| 图不在 / 后缀不认 / 超过 8MB | `[看图] 图片不在: …` 之类一句人话，退出码 1 | **照说**这句，别自己改口 |
| 主路挂了（超时 / 报错 / 空） | 自动落兜底；成了就在头部标 `本地` | 正常回报，但要知道这次是本地读的 |
| 兜底没带 `--mmproj` | 报错里有 `image input is not supported` | 照实说"本地这条路没配好"，**不要**换成自己猜 |
| 两条路都不通 | `[看图] 两条路都不通 —— 图里有什么, 我不知道 (绝不编)`，退出码 1 | **照实说看不到了**。★ 这是最要紧的一条：**不许拿图上可能有什么糊过去** |
| 图上确实没内容（纯色 / 空白） | 模型会说"没看到内容" | 照说"图上没有内容" |
| 这一轮看太多张（默认 100） | 闸的话很直白，退出码 2 | 照说，别绕（闸是防钻牛角尖的） |

## 注意事项

1. **别替它总结**：它看到什么就交什么。你要复述就给**原文**（图上的字照抄），别改写成"大意"。
2. **谁读的要说出来**：头部那个 `云端 / 本地` 就是账。出了错分得清是哪条路的问题。
3. **问句要具体**：默认问句是"这图里有什么"，泛。你知道要找什么就写进 `--问`
   （"标题是什么""有几个柱子""验证码是几位"），答得准得多。
4. **看图比取页贵**（多一次模型调用，走云端还要花钱），所以别拿它当"顺手扫一遍"的工具 —— 那个 100 是**闸**（防钻牛角尖），不是**额度**。
