## 状态 · 两条路各通不通 + 本轮还剩几次

**用途**：看图前想知道会走哪条；看图失败了想知道卡在哪条路上。

**用法**：`.venv/bin/python skill/vision/main.py 状态 [--真读] [--json]`

**选项**：

| 选项 | 说明 |
|---|---|
| `--真读` | 拿一张 1x1 的图**真读一次兜底那条** —— 这是唯一能证明「本地这支带没带 mmproj」的判据 |
| `--json` | 出 JSON |

**示例**：

- `状态`　→ 两条路的端点 / 模型 / 凭据在不在 ＋ 本轮还剩几次
- `状态 --真读`　→ 顺带验证本地**能不能真读图**（不带 `--mmproj` 时会回 `image input is not supported`）

**备注**：

① **凭据只报"在不在"，不打印值。**
② 端点答话（`/models` 200）**不等于能读图** —— 那只是"服务活着"。要判"能不能读图"必须 `--真读`。
③ 兜底那条的成立前提：起本地模型时带了 `--mmproj`（`start_models.sh`），否则它一直是个假的兜底。
