# sha256sum · 算/校验 SHA-256

**用途**：算文件的 SHA-256 指纹 —— 同 md5sum，但更安全（防篡改用这个）。

**用法**：sha256sum [选项] [文件]...

**常用选项**
- `-c 清单文件`　按清单逐项校验
- `--status`　不输出，只看退出码
- `--quiet`　只报失败的
- `--ignore-missing`　清单里缺的文件跳过

**示例**
- `sha256sum 文件`　算指纹
- `sha256sum -c 清单.sha256`　校验（全对才 0）
- `sha256sum 目录/*.tar.gz | sort > 清单.sha256`　生成清单
- `命令 | sha256sum`　算一段文本/管道内容的指纹

**备注**：★ 指纹是 **64 位十六进制**；和官方给的对比要逐字符看（少一位多看一位都算不匹配）。★ 校验大文件是纯 IO 活、很占盘，别和别的重活同时跑。★ 官方发版页通常给 `SHA256SUMS` 文件，`-c` 直接核（本机下载工具链时用过这条路）。★ 批量并行可用 `xargs -P4 sha256sum`。
