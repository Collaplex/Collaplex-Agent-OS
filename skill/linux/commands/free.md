# free · 看内存

**用途**：显示物理内存和交换空间的使用情况（总量、已用、空闲、缓存）。

**用法**：free [选项]

**常用选项**
- `-h`　人类可读（最常用）
- `-m`　以 MB 为单位
- `-g`　以 GB 为单位
- `-s 秒数`　每隔几秒刷新一次（`-s 2`）
- `-t`　多一行总计

**示例**
- `free -h`　一眼看内存和 swap
- `free -h -s 2`　每 2 秒刷一次，看内存变化
- `free -m | awk 'NR==2{print $7" MB 可用"}'`　只要可用内存

**备注**：看 **available** 那列，不是 free 那列（缓存占着也算可用）。本机 16G 内存、核显占 2G、Windows VM 常驻 10G —— 所以宿主看着只剩 2G 左右、开始吃 swap 是**正常现象**，不是内存泄漏。
