# tail · 看文件末尾

**用途**：输出文件的最后若干行（默认 10 行）；加 `-f` 可以实时跟踪正在写的日志。

**用法**：tail [选项]... [文件]...

**常用选项**
- `-n 50`　最后 50 行（`-n +10` 表示从第 10 行开始）
- `-f`　跟踪追加的内容（日志必备）
- `-F`　跟踪并按名字重新打开（日志轮转后仍跟得住）
- `-c 字节数`　按字节输出

**示例**
- `tail -n 50 logs/refine.log`　看最后 50 行
- `tail -F logs/refine-实时.log`　盯着日志看
- `tail -n 200 logs/chat.log | grep 错误`　日志尾部里找报错
- `tail -f log | grep --line-buffered 关键字`　边跟边过滤

**备注**：本机 `tail` 是 **Rust 版（uutils）**（`--help` 英文）。看日志优先 `-F` 而不是 `-f` —— 日志被轮转或重建时 `-f` 会跟丢。★别一次 `tail -n 100000`，几百 KB 灌进模型上下文就没了。
