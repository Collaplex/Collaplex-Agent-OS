# scp · 跨机拷文件

**用途**：通过 SSH 复制文件/目录到远端，或从远端拉回来。

**用法**：scp [选项] 源 目标

**常用选项**
- `-r`　目录递归
- `-P 2222`　★ 指定端口（**大写 P**；ssh 里是小写 p）
- `-i 私钥`　指定密钥
- `-C`　传输时压缩
- `-p`　保留时间戳/权限
- `-v`　调试（连不上看它卡在哪）

**示例**
- `scp 文件 root@192.168.10.1:/root/`　传上去
- `scp -P 2223 root@127.0.0.1:/root/x .`　指定端口拉回来
- `scp -r 目录/ 用户@主机:/目标/`　整个目录
- `scp -i ~/.ssh/id_ed25519 文件 用户@主机:/路径/`

**备注**：★ **端口参数是大写 `-P`**（写小写会变成"保留时间戳"，然后连不上 22）。★ 本机踩过：往手机 PRoot 那类环境传文件，**登录 banner 会混进数据流污染文件** —— 那种场合用 `tar cf - 目录 | ssh 主机 "tar xf - -C /目标"` 走管道。★ 远端路径带空格要转义。
