# ln · 建链接

**用途**：做软链接（快捷方式，加 `-s`）或硬链接（同一份数据的另一个名字）。

**用法**：ln [选项]... 目标 链接名

**常用选项**
- `-s`　软链接（★ 日常要的就是这个；不加是硬链接）
- `-f`　已存在就覆盖
- `-n`　目标是"指向目录的软链"时，替换链接本身而不是往里建
- `-sfn`　★ 换软链的惯用组合（改指向最稳）

**示例**
- `ln -s /真实的/路径 快捷名`　建软链
- `ln -sfn /新目标 已有软链`　★ 改指向（顺序：先目标、后链接名）
- `ln -s /mnt/data/大目录 ~/大目录`　把大目录挂到家目录省根分区
- `ls -l 链接名`　看它指向哪

**备注**：★ 参数顺序容易搞反：**`ln -s 目标 链接名`**（和 `cp 源 目标` 同方向）。★ 用相对路径建软链时，那是"相对于链接所在目录"解析的 —— 拿不准就用**绝对路径**。★ 本机不少资源靠软链腾空间（`~/归档` → 归档盘、`~/.steam` → /mnt/data）：**删软链不会删数据**，但 `rm -r 链接名/` 跟进去就会真删。
