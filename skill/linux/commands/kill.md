# kill · 给进程发信号

**用途**：向进程发送信号，默认发 SIGTERM（15，礼貌请它退出）；也能查信号表。

**用法**：kill [-s 信号名 | -n 信号号 | -信号名] PID...　|　kill -l [信号]

**常用选项**
- `-l`　列出所有信号名（`kill -l 9` 反查名字）
- `-s TERM` / `-TERM`　指定信号
- `-9`　SIGKILL 强杀（收不了尾，别一上来就用）
- `-HUP`　让不少守护进程重新读配置

**示例**
- `kill 1234`　礼貌请它退出
- `kill -9 1234`　它不理就强杀
- `kill -l`　看信号表
- `pkill -f '[m]y_script.py'`　按命令行批量杀（pkill 是 kill 的表兄弟）

**备注**：★先 `ps aux` 认准归属再杀 —— 本机上有老板的游戏、Windows VM、GUI Blender 在跑，绝不裸 `pkill -x python` 或宽松的 `pkill -f python`。★杀父进程不等于杀干净子进程（子进程会变孤儿继续跑、继续写同一个文件），要按 PID 逐个杀、杀完复查一遍。★`pkill -f` 的匹配串要够特异，它也会匹配到你自己那条命令。
