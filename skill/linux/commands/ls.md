# ls · 看目录里有什么

**用途**：列出目录内容。

**用法**：ls [选项]... [文件]...

**常用选项**
- `-l`　长格式（权限、大小、时间）
- `-h`　大小人类可读（要跟 `-l` 一起用）
- `-a`　连隐藏文件（`.` 开头）一起列
- `-t`　按修改时间排（`-S` 按大小排）
- `-r`　倒序
- `-d`　只列目录本身，不列里面的内容

**示例**
- `ls -lht ~/桌面/collaplex_agent | head`　最近改过的文件
- `ls -lh logs/`　日志多大、什么时候写的
- `ls -d */`　只看目录
- `ls -la ~/桌面`　含隐藏文件全列

**备注**：★ **本机的"桌面"是中文名 `~/桌面`**（`xdg-user-dir DESKTOP` = `/home/lou/桌面`），**`~/Desktop` 不存在** —— 别拿它当首选路径，答用户时也别写这个不存在的名字（实测写过，列表是 `~/桌面` 的，名字却报了 `~/Desktop`）。本机 `ls` 是 **Rust 版（uutils）**，`--help` 是英文，个别 GNU 选项这里没有（不认就换个写法）。看文件新旧别只看名字 —— `ls -la` 的时间戳是老板抽查中间产物"是不是真重跑过"的依据。
