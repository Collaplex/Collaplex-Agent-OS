# lsusb · 看 USB 设备

**用途**：列出 USB 总线上的设备 —— 摄像头、键盘、USB 硬盘、UPS、Type-C 外设认没认到。

**用法**：lsusb [选项]

**常用选项**
- `-t`　树形（看设备挂在哪个控制器/端口下，排查"插了没认"最有信息量）
- `-d 厂商:产品`　只看指定设备（16 进制 VID:PID）
- `-v`　详细描述符（要 root 才全）
- `-s 总线:设备号`　只看某一个

**示例**
- `lsusb`　一览（每行形如 `Bus 001 Device 003: ID 0b05:19b6 …`）
- `lsusb -t`　★ 树形：看插在哪、驱动是什么
- `lsusb -d 0665:5161`　★ 按 VID:PID 找（本机 UPS 就是这个 ID）
- `watch -n1 lsusb`　插拔时盯着看（不用重敲命令）

**备注**：★ **插了没反应时 `lsusb` 是第一步**：设备层没认到，就别去折腾上层。★ 记 ID 比记名字可靠（同型号换批次名字会变）。★ 本机例子：UPS = `0665:5161`（INNO TECH 桥）、键盘背光 = `0B05:19B6`。★ 认不出设备时看内核怎么说：`journalctl -k | tail -30`（本机免 sudo 可用）。
