# wc · 数行数 / 字数 / 字节

**用途**：统计文件或管道输入的行数、词数、字符数、字节数。

**用法**：wc [选项]... [文件]...

**常用选项**
- `-l`　行数（最常用）
- `-w`　词数
- `-c`　字节数
- `-m`　字符数（中文看这个，`-c` 会把一个字算 3 字节）
- `-L`　最长行的长度

**示例**
- `wc -l 文件.txt`　多少行
- `find . -name "*.md" | wc -l`　有多少个 md
- `ps aux | wc -l`　进程数（含表头，要减 1）
- `wc -lm 中文.txt`　中文的行数与字符数

**备注**：★ **最后一行没有换行符时不算一行**（`printf 'a' | wc -l` 得 0）—— 数出来的行数比预期少一，先想这条。★ 数文件个数用 `find … | wc -l`，别用 `ls | wc -l`（文件名带换行会数错）。
