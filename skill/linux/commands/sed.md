# sed · 流编辑（替换/抽取/删行）

**用途**：按行做文本处理 —— **把文件里的旧字样换成新的（替换）**、删除、抽取指定行。默认只打到屏幕，不改原文件。

**用法**：sed [选项] '脚本' [文件]...

**常用选项**
- `-n`　不自动打全部行（配合 `p` 只打想要的）
- `-i`　★ 直接改**原文件**（危险，先备份）
- `-e '脚本'`　叠加多个脚本
- `-E`　用扩展正则（`+` `?` `|` 不必转义）

**常用脚本**
- `s/旧/新/`　每行第一处（`s/旧/新/g` 全行都换）
- `s/旧/新/gi`　忽略大小写 + 全局
- `5,10d`　删 5~10 行 · `/模式/d`　删匹配行
- `-n '3,7p'`　只打 3~7 行

**示例**
- `sed -i.bak 's/旧/新/g' 文件`　★ 改动并留一份 .bak
- `sed -n '1,20p' 文件`　只看前 20 行
- `命令 | sed 's/^/  /'`　每行加缩进
- `sed -n '/START/,/END/p' 文件`　取两个标记之间的内容

**备注**：★ **`-i` 直接改原文件、没有撤销** —— 动手前 `cp 文件 文件.bak` 或写 `-i.bak`。★ 分隔符不一定是 `/`：带斜杠的路径用 `sed 's|/a/|/b/|g'` 更省事。★ 处理 JSON 别硬 sed，用 `jq`。
