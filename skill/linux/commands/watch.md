# watch · 定时重跑一个命令

**用途**：每隔几秒重跑一条命令、把最新结果铺满屏幕（盯着看变化）。

**用法**：watch [选项] 命令

**常用选项**
- `-n 2`　每 2 秒一次（默认 2 秒）
- `-d`　标出变化的部分（★ 看差别特别好用）
- `-g`　输出一变就退出（脚本里等状态变化）
- `-t`　不显示顶部标题
- `-e`　命令报错就停

**示例**
- `watch -n1 -d 'sensors | grep -A2 k10temp'`　盯 CPU 温度
- `watch -n2 -d nvidia-smi`　盯显存与占用
- `watch -n5 'free -h'`　盯内存
- `watch -g 'pgrep -x 名字 >/dev/null'`　等进程出现就退出

**备注**：★ 裸 `watch` 是**交互界面**（要 Ctrl-C 才退）—— 程序里别用；脚本里要用就配 `-g`。★ 命令里带管道**必须加引号**：`watch -d 'a | b'`。★ 只要一次快照就直接跑命令或用 `top -bn1`，别套 watch。
