# uniq · 去重 / 计数

**用途**：去掉**相邻**重复行，或数每行出现几次 —— 统计频次的老搭档。

**用法**：uniq [选项]... [输入]

**常用选项**
- `-c`　每行前面加上出现次数（最常用）
- `-d`　只显示重复过的
- `-u`　只显示没重复的
- `-i`　忽略大小写

**示例**
- `sort 文件 | uniq -c | sort -rn | head -10`　★ 统计出现最多的十项（经典三连）
- `history | awk '{print $2}' | sort | uniq -c | sort -rn | head`　最常用的命令
- `sort ips.txt | uniq -c | sort -rn`　哪个 IP 出现最多

**备注**：★ **uniq 只去"相邻"重复** —— 不先 `sort` 的话，隔开的重复它看不见（最大的坑）。★ 想保持原顺序去重：`awk '!seen[$0]++'`。★ 数"有几个不重复的文件名"用 `sort -u | wc -l`。
