# chmod · 改文件权限

**用途**：改文件/目录的读(r)写(w)执行(x)权限。

**用法**：chmod [选项]... 权限 文件...

**常用选项**
- `-R`　递归（★ 对目录用之前想清楚）
- `-v`　打印每个改动
- `--reference=参考文件`　照另一个文件的权限设

**常用写法**
- `chmod +x 脚本.sh`　加执行位（最常用）
- `chmod 644 文件`　普通文件：拥有者可写、其他人只读
- `chmod 755 目录`　目录标准权限；`700` 只有自己能进
- `chmod u+w,g-w,o-rwx 文件`　按身份加/减

**示例**
- `chmod +x ~/tools/xxx/跑.sh`
- `chmod 600 ~/.ssh/config`　私密文件收紧
- `chmod -R 755 站点目录`　让 nginx 能读（★ 目录必须有 x）

**备注**：★ 数字是**三位八进制**：4=读 2=写 1=执行，相加（644 / 755 / 600）。★ **`chmod -R 777` 会被护栏拦**（既危险也没必要）—— 目录给 755、文件给 644 就够，站点文件还要 `o+r,o+x` 否则 nginx 403。★ 加执行位后没生效，先确认盘不是 `noexec` 挂的（`mount | grep 挂载点`）。
