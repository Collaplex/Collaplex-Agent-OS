# which · 命令在哪 / 装了没

**用途**：按 PATH 找命令位置 —— 确认"装了没、装在哪、用的是哪一个"。

**用法**：which [-a] 命令...

**常用选项**
- `-a`　列出 PATH 里**所有**同名（排查"为什么跑的是旧版本"）
- `-s`　不输出，只用退出码表示找没找到

**示例**
- `which python3 nvidia-smi`　装了没、在哪
- `which -a python3`　★ 有多个时全列出
- `command -v 命令`　★ 更通用（别名/函数/内建也查得到，which 查不到）
- `ls -l $(which 命令)`　看它是不是软链接、指向哪

**备注**：★ `which` 找不到 ≠ 没装 —— 可能只是不在 PATH（用 `find / -name 名字 2>/dev/null` 兜底）。★ 判"这个 python 属于哪个 venv"必须 `ls -l` 解开软链看真实路径（本机 Hermes 菜单崩溃就是软链被 resolve 解错导致的）。★ `type 命令` 还能告诉你它是别名/函数/内建。
