# tar · packaging / 解包

**用途**：把一堆文件打成一个归档（可压缩），或解开。

**用法**：tar [选项]... 归档 [文件...]

**常用选项**
- `-c` 建包 · `-x` 解包 · `-t` 只看里面有什么
- `-f 文件`　★ 指定归档名（必须紧挨着文件名）
- `-z` gzip · `-J` xz · `-j` bzip2
- `-v`　列出处理的文件
- `-C 目录`　换目录（以哪儿为基准）
- `--exclude=模式`　排除

**示例**
- `tar -czf 备份.tar.gz 目录/`　压缩打包
- `tar -xzf 包.tar.gz -C /目标/`　解到指定目录
- `tar -tzf 包.tar.gz | head -20`　先看里面有什么再解
- `tar cf - 目录 | ssh 用户@主机 "tar xf - -C /目标"`　★ 管道直传（不落中间文件）

**备注**：★ `-f` 后面**必须紧跟文件名**（老式写法 `tar cvf` 的顺序不能乱）。★ 解包前先 `-t` 看一眼，并用 `-C` 指定目录，防"解出一堆文件铺满当前目录"。★ 本机往手机/软路由传文件就用 tar 管道（那边 busybox 没有 rsync，scp 还会被 banner 污染数据）。
