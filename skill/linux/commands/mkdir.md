# mkdir · 新建目录

**用途**：建目录（一层或多层）。

**用法**：mkdir [选项]... 目录...

**常用选项**
- `-p`　父目录不存在就一起建（`mkdir -p a/b/c`）；目录已存在也不报错
- `-m 权限`　建的时候直接给权限，如 `-m 755`、`-m 700`
- `-v`　每建一个打印一行

**示例**
- `mkdir build`　建一层
- `mkdir -p data/logs/2026`　多层一次建好
- `mkdir -m 700 私密/`　建出来就是仅自己可读写执行

**备注**：不加 `-p` 时父目录不存在会报 "No such file or directory"。本机 `mkdir` 是 Rust 版（uutils，英文帮助）。
