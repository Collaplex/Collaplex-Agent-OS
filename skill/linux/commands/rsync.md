# rsync · 增量同步

**用途**：同步文件/目录 —— 只传变化的部分，可续传、可删多余文件。比 `scp` 适合大目录。

**用法**：rsync [选项] 源 目标

**常用选项**
- `-a`　归档模式（递归 + 保留权限/时间/链接，最常用）
- `-v`　列出处理的文件 · `-h`　人话单位
- `-z`　传输压缩（跨网络用）
- `-P`　★ 进度 + 断点续传（大文件必备）
- `--delete`　★ 让目标和源**完全一致**（目标里多出来的会被删）
- `-n`　★ **演习**：只说干什么、不真动（和 `-v` 配着先跑一遍）
- `--exclude=模式`　排除
- `-e "ssh -p 2223"`　指定 ssh 端口

**示例**
- `rsync -avn --delete 源/ 目标/`　★ 先演习
- `rsync -avP 源/ 用户@主机:/目标/`　真同步（带进度续传）
- `rsync -avz --exclude=.git 项目/ 备份/`　排除 .git
- `rsync -av -e "ssh -p 2223" 目录/ root@主机:/路径/`

**备注**：★ **源目录结尾的斜杠有讲究**：`源/` = 同步里面**的内容**；`源` = 把整个目录放进目标（多一层）—— 传错就多一个文件夹。★ 先 `-avn` 演习，看清要删什么再上 `--delete`。★ 本机 rsync **3.4.1** ✓；手机/软路由那类只有 busybox 的环境没有 rsync，走 tar 管道。
