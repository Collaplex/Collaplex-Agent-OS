# date · 看时间（和换算）

**用途**：打印或设置系统日期时间，也能按格式输出、做时间换算。

**用法**：date [选项]... [+格式]　|　date [选项]... [MMDDhhmm[[CC]YY][.ss]]

**常用选项**
- `+%F %T`　格式化输出（`+%F` 只要日期）
- `-d '昨天'` / `-d '2 hours ago'`　相对时间
- `-d @1700000000`　时间戳转日期（`+%s` 反过来取时间戳）
- `-u`　UTC
- `-R`　RFC 2822 格式
- `--iso-8601=seconds`　带时区的 ISO 格式

**示例**
- `date`　现在几点
- `date '+%F %T %Z'`　2026-10-06 13:47:00 CST
- `date -d '30 minutes ago' '+%F %T'`　半小时前
- `date +%s`　当前时间戳

**备注**：本机时区 `Asia/Shanghai`，`date` 是 **Rust 版（uutils）**。★报时间**必须真的跑一次 `date`**，不许凭对话长短猜（这项目里因此被纠正过两次）。改系统时间要 sudo，一般别改。
