# rm · 删除文件/目录

**用途**：删掉文件或目录（真的删掉，不进回收站、不可恢复）。

**用法**：rm [选项]... [文件]...

**常用选项**
- （无）　默认删文件；目录会报 "is a directory"，删不动
- `-i`　每个都问；`-I`　删超过 3 个或递归删目录时问一次
- `-r, -R`　递归删目录**及其内容**
- `-d`　只删空目录（非空报错，安全）
- `-v`　打印删了什么
- `-f`　强制（**不用**：配 `-r` 就是 `-rf`，会被拦）

**示例**
- `rm logs/junk.txt`　删一个文件
- `rm -v a.txt b.txt`　删多个并打印删了哪些
- `rm -r build/`　删一个**确认过的**目录（先 `ls build/`）
- `ls /tmp/*.tmp && rm /tmp/xxx.tmp`　先列出来再删（推荐顺序）

**备注**：①**`rm -rf` 一律被拦**（`-r` 和 `-f` 同时出现就拦）：删目录用 `rm -r <目录>`，删文件用 `rm <文件>`。②**宽目标被拦**：`/`、`/tmp`、`~`、`/home/lou`、`*`、`.`、`..` 这类整个盘/家目录级别的目标，不管带不带 `-f` 都拦（`rm /tmp/*` 这种通配也拦）—— 要清就逐个点名：`rm /tmp/xxx`。③删之前先 `ls` 看清是哪几个，删错了没有回收站。本机 `rm` 是 GNU 版（中文帮助）。
