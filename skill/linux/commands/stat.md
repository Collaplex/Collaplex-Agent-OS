# stat · 看文件的详细属性

**用途**：一个文件的时间戳（三个）、权限、大小、inode、硬链接数。

**用法**：stat [选项]... 文件...

**常用选项**
- `-c '%y'`　自选字段输出（见下）
- `-L`　跟软链接（默认显示链接本身的信息）
- `-f`　显示所在**文件系统**的信息
- `-t`　精简一行

**常用字段**
- `%n` 文件名 · `%s` 字节 · `%y` 修改时间(人话) · `%a` 八进制权限
- `%U/%G` 属主/属组 · `%i` inode · `%h` 硬链接数 · `%F` 文件类型

**示例**
- `stat 文件`　全量信息
- `stat -c '%y %s %n' *`　★ 一行一个文件的修改时间 + 大小（查产物新旧）
- `stat -f -c '%T' /mnt/data`　这个挂载点是什么文件系统（ext4/ntfs/tmpfs）

**备注**：★ 三个时间戳含义不同：**Modify（内容改动）/ Change（元数据改动）/ Access（被读）** —— 判"文件是不是刚生成"看 **Modify**。★ 查产物新旧用 `stat -c '%y %n'` 或 `ls -la --time-style=full-iso`。★ `Access` 时间常因 `relatime` 而不准，别拿它当"最近有没有被读过"的证据。
