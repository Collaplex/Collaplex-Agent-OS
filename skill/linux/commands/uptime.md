# uptime · 看负载与开机时长

**用途**：一行给出当前时间、开机多久、登录人数、1/5/15 分钟平均负载。

**用法**：uptime [选项]

**常用选项**
- `-p`　只留"up 6 hours, 41 minutes"这种人话
- `-s`　开机时刻

**示例**
- `uptime`　完整一行
- `uptime -p`　开机多久（人话）
- `uptime -s`　哪天几点开的机

**备注**：★ 负载高**不等于**出故障：本机常年跑本地模型（llama-server 满速能把 load 顶到 10+，2026-10-06 实测 11.80），要看的是"跟平时比异常没"。★ load 的分母是**核数**（本机 16 核 32 线程），load 到 16 才等于满载。★ 想知道谁在吃 CPU 用 `top -bn1 -o %CPU | head -14`。★ 判机器卡死别只看 load —— 端口通+load 正常但应用层不答，那是内存僵死（另见排查记录）。
