# diff · 比两个文件的差异

**用途**：逐行比两个文件（或新旧版本），只列出不同的地方。

**用法**：diff [选项]... 文件1 文件2

**常用选项**
- `-u`　统一格式（`git diff` 那种，最常看）
- `-q`　只报"一样/不一样"，不列内容
- `-r`　递归比目录
- `-i`　忽略大小写
- `-w`　忽略空白差异
- `-y`　左右并排
- `-s`　相同时也报一声

**示例**
- `diff -u 旧.conf 新.conf`　看改了什么
- `diff -rq A/ B/`　递归比目录，只列不同的文件
- `diff -q 文件1 文件2`　变了没（看退出码）
- `diff <(命令1) <(命令2)`　比两条命令的输出（进程替换）

**备注**：★ **退出码就是结论：0 = 一样，1 = 有差异，2 = 出错**（写判断时用得着）。★ 只想知道"变了没"用 `-q`，别把整份 diff 灌进上下文。★ 比二进制文件它只会说"differ"—— 要比字节用 `cmp` 或 `md5sum`。
