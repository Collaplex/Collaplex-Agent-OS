# md5sum · 算/校验 MD5

**用途**：算文件指纹 —— 校验有没有传坏、判断两个文件是不是同一份。

**用法**：md5sum [选项] [文件]...（不给文件就读标准输入）

**常用选项**
- `-c 清单文件`　★ 按清单逐项校验
- `--status`　不输出，只看退出码（脚本里用）
- `--quiet`　只报失败的
- `-w`　格式不对的行给警告

**示例**
- `md5sum 文件.iso`　算指纹
- `md5sum *.deb | sort`　一批文件的指纹
- `md5sum -c 清单.md5`　★ 逐项校验（全对才返回 0）
- `md5sum 文件A 文件B`　指纹相同 = 内容相同（判重复）

**备注**：★ MD5 **只能用来查"传坏没/是不是同一份"，不能用来验安全性**（能被构造碰撞）—— 防篡改用 `sha256sum`。★ 校验大文件要等它读完（几百 GB 很慢）。★ 只想知道"两个文件一样吗"，`cmp -s A B; echo $?` 比算哈希快得多。★ 本机习惯：归档到盘/传手机后都算一遍核对。
