# pkill · 按名字杀进程

**用途**：按名字/命令行特征匹配并发信号（默认 TERM）—— `pgrep` 的"执行"版。

**用法**：pkill [选项] 模式

**常用选项**
- `-f`　★ 匹配**完整命令行**（不只进程名）
- `-x`　名称完全相等才匹配（防误伤）
- `-u 用户`　只杀某用户的
- `-9`　强杀（SIGKILL，最后手段）
- `-e`　杀的时候报出来
- `-c`　只数有几个匹配

**示例**
- `pgrep -af 名字`　★ **先看再杀**（列出 PID + 完整命令行）
- `pkill -f 'python.*crawler'`　按命令行特征杀
- `pkill -x cava`　精确按名杀
- `pkill -9 -f 特征`　强杀

**备注**：★★ **`pkill -f 模式` 会匹配到你自己那条命令**（命令行里就含这个模式）→ 等于自杀 —— 本机踩过：`pkill -f aria2c` 把发命令的 shell 一起杀了。所以：**先 `pgrep -af` 看**，模式要够特异（用 `[a]ria2c` 这种字符类破自匹配）。★ 杀之前先 `ps aux` 看**完整路径**认归属（本机 snap 版 Blender 和 `~/Applications` 里的 Blender 是两个东西）。★ 杀父进程不等于杀子树 —— 子进程会变孤儿继续跑，要一起收。
