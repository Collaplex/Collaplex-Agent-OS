# pgrep · 按名字或命令行找进程

**用途**：按进程名或完整命令行匹配，只输出 PID（加 `-a` 连命令行一起出），比 `ps | grep` 干净。
问"**我这程序还在跑吗** / 某个进程还在不在"就用它。

**用法**：pgrep [选项] <模式>

**常用选项**
- `-a`　连完整命令行一起出（`-l` 只出进程名）
- `-f`　匹配完整命令行，而不只是进程名
- `-c`　只输出匹配到几个
- `-u 用户`　限定某个用户
- `-n` / `-o`　只要最新 / 最老的那个
- `-v`　反向，不匹配的

**示例**
- `pgrep -a python`　找 python 进程及其命令行
- `pgrep -c -f crawl_marathon`　后台爬虫在跑几个
- `pgrep -u lou -a node`　只看自己用户的
- `pgrep -a -f '[c]hrome'`　防自杀写法（见备注）

**备注**：★`-f` 会把**你自己这条命令**也匹配进去（命令行里含同样的字），要精确匹配就用字符类岔开，比如 `pgrep -f '[a]ria2c'`。本机软路由那侧是 OpenWrt busybox，连 pgrep 都没有，只能 `ps | grep`。
