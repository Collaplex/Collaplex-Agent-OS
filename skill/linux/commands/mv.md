# mv · 移动/重命名

**用途**：把文件或目录挪个地方；同一个目录内挪 = **改名字**。原处那份不在了。

**用法**：mv [选项]... 源 目标

**常用选项**
- `-i`　目标已存在就先问（重命名时最该带）
- `-n`　目标已存在就不动
- `-f`　直接覆盖（不问）
- `-v`　打印每一步
- `-u`　只在源更新时才覆盖
- `-t 目录`　把后面所有源都挪进这个目录

**示例**
- `mv old.txt new.txt`　改名
- `mv a.txt /tmp/`　挪进另一个目录
- `mv -i 草稿.md 定稿.md`　怕覆盖就先问
- `mv -t 归档/ a.txt b.txt c.txt`　一次挪一堆进同一个目录
- `mv data/ 归档/data-20261006/`　目录整体挪/改名

**备注**：同名覆盖是**静默**的，所以重命名前先 `ls` 或直接 `mv -i`。跨文件系统挪大目录其实是在"复制 + 删除"，会慢。本机 `mv` 是 GNU 版（中文帮助）。
