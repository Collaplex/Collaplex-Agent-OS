# top · 实时看进程（快照版）

**用途**：进程排行 + 系统总览（负载/CPU/内存/交换）。

**用法**：top [选项]

**常用选项**
- `-b`　批处理模式（**非交互**，能进管道；不带它就没法在程序里用）
- `-n 1`　只出一轮快照就退出
- `-o %MEM`　按内存排序（`-o %CPU` 按 CPU）
- `-H`　线程粒度
- `-c`　显示完整命令行

**示例**
- `top -bn1 | head -12`　一轮快照（前 5 行是系统总览，之后才是进程）
- `top -bn1 -o %MEM | head -15`　谁最吃内存
- `top -bn1 -o %CPU | head -15`　谁最吃 CPU

**备注**：★ 裸 `top` 是**交互界面**（要按键、不会自己退）—— 程序里必须 `-bn1`，否则会挂住。★ 总览里的 load average 和 `uptime` 一个口径，别单独解读。★ 按名字精确找进程用 `pgrep -af 名字`，别 `top | grep`（会连自己的 grep 一起数进去）。
