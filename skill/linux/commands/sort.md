# sort · 排序

**用途**：把行按某种顺序排 —— 数字大小、字典序、按某列、按人类可读的大小（1.2G）。

**用法**：sort [选项]... [文件]...

**常用选项**
- `-n`　按数字大小（不加这个，"10" 会排在 "9" 前面）
- `-h`　按人类可读大小（KB/MB/GB 混排也对）
- `-r`　倒序
- `-k 4`　按第 4 列排（`-k4,4n` = 第 4 列按数字）
- `-u`　排完去重
- `-t,`　指定分隔符（默认空白）

**示例**
- `du -sh * | sort -h`　谁最占空间（从小到大）
- `du -sh * | sort -hr | head -10`　★ 最大的十个
- `df -h | sort -k5 -hr`　按占用百分比排
- `sort -u 名单.txt`　排序并去重

**备注**：★ 数字列**不加 `-n` 会按字符串排**（"100" 排到 "99" 前面），这是最常见的错。★ 要和 `uniq` 配合时**必须先 sort**（uniq 只处理相邻重复）。
