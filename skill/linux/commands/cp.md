# cp · 复制文件/目录

**用途**：复制文件或目录（目录要带 `-r`）。**不是移动** —— 原处那份还在（要移动用 `mv`）。

**用法**：cp [选项]... 源 目标

**常用选项**
- `-r, -R`　复制目录时必须带
- `-a`　归档式复制：递归 + 保留权限/时间/软链（备份用这个）
- `-i`　目标已存在就先问
- `-n`　目标已存在就跳过（不覆盖）
- `-u`　只在源比目标新（或目标不存在）时才复制（增量补）
- `-v`　打印复制了哪些
- `-l`　建硬链接代替复制（同分区、省空间）

**示例**
- `cp a.txt b.txt`　复制一份
- `cp a.txt 备份/`　复制到目录里（同名）
- `cp -a src/ dst/`　整棵目录连属性一起复制
- `cp -u *.log 归档/`　只搬新的
- `cp -rv data/ data-backup/`　看得到搬了哪些

**备注**：`cp f1 f2`（目标是文件）会**覆盖** f2，想稳一点用 `-i` 或 `-n`。目标目录不存在时 `cp -r src/ dst/` 会把 dst 当新目录名建出来，别和"复制进 dst/ 里面"搞混（那个要 `cp -r src dst/`，dst 要先存在）。本机 `cp` 是 GNU 版（中文帮助）。
