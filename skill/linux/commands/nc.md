# nc · 端口探测 / 裸连接

**用途**：开一条裸 TCP/UDP 连接 —— 探端口开没开、手动发一段请求、临时传数据。

**用法**：nc [选项] 主机 端口

**常用选项**
- `-z`　★ 只探端口、不发数据
- `-v`　说话（报结果）
- `-w 3`　超时秒数
- `-l 端口`　监听（当服务端）
- `-u`　UDP
- `-k`　监听时保持（收多个连接）

**示例**
- `nc -zvw3 127.0.0.1 8789`　★ 这个端口通不通（有服务在听就成功）
- `nc -zvw3 主机 22 80 443`　一次探几个
- `printf 'GET / HTTP/1.0\r\n\r\n' | nc -w3 主机 80`　手写请求看响应
- `nc -l 9000 > 收到的文件`　临时接收端

**备注**：★ **`nc -z` 只证明"端口有东西在听"，不证明应用层活着** —— 判服务死活要打 HTTP（`curl -sI`）；本机踩过"端口通但应用僵死"（内存打满那次）。★ 本机看端口更常用 `ss -ltnp`（不用连过去、还能看到进程）。★ `-z` 对公网大范围扫会被当攻击，别对别人的机器用。
