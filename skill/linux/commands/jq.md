# jq · 处理 JSON

**用途**：命令行里查/取/改 JSON —— 从接口返回或文件里精确掏字段，比 grep 靠谱。

**用法**：jq [选项] '过滤表达式' [文件]

**常用选项**
- `.`　原样美化输出（看结构的第一步）
- `-r`　字符串去引号（要纯文本时用）
- `-c`　紧凑单行
- `-s`　把输入全部读成一个数组

**常用表达式**
- `.a.b`　取嵌套字段 · `.[]`　展开数组 · `.[0]`　第一个
- `.[] | .name`　每项的某个字段
- `{名字: .name, 端口: .port}`　重新拼对象
- `length`　长度 · `keys`　所有键 · `has("x")`　有没有这个键

**示例**
- `curl -s --noproxy '*' http://127.0.0.1:8790/v1/models | jq -r '.data[].id'`　★ 列出模型名
- `jq '.usage' 响应.json`　看某个对象
- `jq -r '.[] | "\(.pid) \(.mem)"' 列表.json`　拼成两列文本
- `jq '.a // "默认"' 文件`　取不到就给默认值

**备注**：★ 拿到一份 JSON 先用 `.` 看结构再写表达式（瞎猜字段名最费时间）。★ 要**纯文本结果**（进管道/给模型看）必须加 `-r`，否则带引号。★ 本机 jq **1.8.1** 已装 ✓。★ 它不做原地修改：改文件用 `jq … 文件 > 新文件`。
