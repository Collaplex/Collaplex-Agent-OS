# du · 看目录和文件占多少空间

**用途**：估算文件和目录占用的磁盘空间；默认逐目录递归显示。

**用法**：du [选项]... [文件]...

**常用选项**
- `-s`　每个参数只给一个总计（最常用）
- `-h`　人类可读
- `-d N`　只统计到第 N 层（`-d 1` = 只看直接子目录）
- `-a`　连文件也列出来
- `-c`　末尾加一行总计
- `-x`　不跨文件系统（别把挂进来的盘算进去）
- `-S`　不把子目录的空间算进父目录那一行
- `--exclude=模式`　跳过匹配的文件

**示例**
- `du -sh ~/桌面`　这个目录一共多大
- `du -h -d 1 ~/桌面 | sort -h`　各子目录占多少，从小到大
- `du -sh ~/桌面/* | sort -h | tail -5`　占得最多的 5 个
- `du -x -sh ~/`　只算本分区的（不跟进挂载进来的盘）

**备注**：不带 `-s` 又会列到每个子目录，几千行很正常，配合 `sort -h | tail` 看大头。慢是正常的（要遍历目录）。本机 `du` 是 **Rust 版（uutils）**，`--help` 是英文，个别选项跟 GNU 版有出入。
