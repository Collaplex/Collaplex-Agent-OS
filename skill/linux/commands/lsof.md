# lsof · 谁占着这个文件或端口

**用途**：列出进程打开的文件、目录、socket、管道 —— 反查"这东西到底是谁占着的"。

**用法**：lsof [选项] [names]

**常用选项**
- `-i`　网络连接；`-i :端口` 看某个端口
- `-p PID`　某个进程打开了哪些文件
- `-u 用户`　某个用户的
- `+D 目录`　某目录下被打开的文件（慢）
- `-t`　只输出 PID（方便接着 kill）

**示例**
- `lsof -i :8789`　谁占着 8789
- `lsof -p 1234`　这个进程开着哪些文件
- `lsof +D ~/桌面/collaplex_agent`　谁在用这个目录
- `kill -9 $(lsof -t -i :8789)`　占端口的直接干掉

**备注**：本机 lsof 4.99.4，**不认 `--help`**（要看帮助用 `lsof -h`）。看别的用户的进程要 sudo。找不到占用者时先想想 systemd socket 激活 —— 进程可能刚自动退出，端口是 socket 单元留着的。
