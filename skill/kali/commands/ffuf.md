# ffuf · Web 目录 / 参数 / 子域爆破

**用途**：**扫一个网站有哪些目录、页面、备份文件**（目录扫描 / 目录爆破 —— 把词表里的词挨个替换进 URL 的 `FUZZ` 位置去请求，看哪些路径真的存在），也能扫子域、请求头、参数值。特点是快、过滤规则细、`FUZZ` 能放在任意位置（URL、Header、Body）。★ 找**网站目录/隐藏文件**用这个；扫**端口/服务**才算 `nmap.md` 的活。*只对自有或已授权目标跑。*

**用法**：ffuf -w 词表 -u URL/FUZZ [选项]

**常用选项**
- `-w 词表[:关键字]`　词表（**必给**）。默认关键字 `FUZZ`；可写成 `-w 词表:VALUE` 把词打进别的占位符（配合多词表）
- `-u URL`　目标，`FUZZ` 是占位符；`-H "名: 值"`　自定义请求头（可多次）；`-b "K=V; K2=V2"`　Cookie；`-X POST`　方法；`-d '数据'`　请求体
- `-e html,bak,txt`　给 `FUZZ` 自动追加扩展名；`-D`　DirSearch 词表兼容模式（配合 `-e`）
- `-request 请求.txt -request-proto http`　直接从抓好的原始 HTTP 请求文件读目标（比手工拼 headers 省事）
- `-mc 200,301,302`　只看这些状态码，也接范围如 `200-299`；`-fc 404`　过滤掉这些状态码
- `-fs 0`　按响应**大小**过滤（找子域最有用：不存在的子域大小都一样）；`-fw`（词数）/ `-fl`（行数）/ `-fr "正则"` 同理
- `-ac`　★ **自动校准**：先发一批"必然不存在"的随机请求，把基线响应的大小 / 词数记下来自动过滤 —— 专治**通配符 404**（目标对任意路径都回一样内容，此时 `-fc 404` 没用，因为状态码可能是 200）
- `-recursion`　对找到的目录继续往下爆（`-u` 必须以 `FUZZ` 结尾）；`-recursion-depth 2`　限层数；`-recursion-strategy greedy`　所有命中都递归（默认只跟 301 跳转递归）
- `-t 40`　并发线程（默认 40）；`-rate 50`　每秒请求上限；`-p 0.1`　每请求间延时（也接 `0.1-2.0` 随机区间）
- `-s`　静默，只出结果；`-c`　彩色；`-v`　显示完整 URL 与跳转目标
- `-o 结果.json -of json`　存文件，`-of` 支持 `json/ejson/html/md/csv/ecsv/all`；`-od 目录`　命中响应逐条落盘
- `-mode clusterbomb|pitchfork|sniper`　多词表时的组合方式；`-x http://127.0.0.1:8080`　代理；`-timeout 10` / `-maxtime 60`　超时与整轮时限

**示例**（全部打本机靶）
- `ffuf -w 词表 -u http://127.0.0.1:8789/FUZZ -s`　★ 扫这个网站有哪些目录 / 隐藏页面（最常用）
- `ffuf -w 词表 -u http://127.0.0.1:8789/FUZZ -ac -s`　★ 通配符场景先加 `-ac` 自动校准
- `ffuf -w 词表 -u http://127.0.0.1:8789/FUZZ -mc 200,301,302 -fs 0`　滤掉空响应，结果干净得多
- `ffuf -w 词表:SUB -u http://127.0.0.1/ -H "Host: SUB.local" -fs 0`　虚拟主机 / 子域枚举（本机走 Host 头）
- `ffuf -w 词表 -u "http://127.0.0.1:8789/api?id=FUZZ" -fs 0`　参数枚举
- `ffuf -w 词表 -u http://127.0.0.1:8789/FUZZ -e .html,.bak -of csv -o r.csv`　带扩展名并导 CSV，方便表格里排序去噪

**备注**：★ 本机 ffuf **2.1.0-dev**。★ **本机一个词表都没有**（`/usr/share/wordlists` 目录都不存在）—— `-w` 得自己造；实测用自制的 5 行小词表就能跑。★ **`-mc all` 会把 404 也列出来**：实测对本机 8789 面板用 5 个词 + `-mc all`，5 个全"命中"，看着像全找到了，其实大多是 404 —— **排查先看状态码列，别只看有输出**。★ 不加 `-mc`/`-fc` 时默认只匹配 `200-299,301,302,307,401,403,405,500`（实测默认只打出确实存在的 `index.html`；启动 banner 里 `:: Matcher` 那行会写出当前匹配规则）。★ 实测加 `-fc 404` 或 `-ac` 都能把 404 滤干净、只留真命中。★ **HUGE 输出怎么读**：非静默时每条命中的行格式是 `词  [Status: 状态码, Size: 大小, Words: 词数, Lines: 行数, Duration: 耗时]`（实测 `index.html [Status: 200, Size: 24211, Words: 2801, Lines: 499, Duration: 1ms]`）—— **先按 Size / Words 排序找"同一个值反复出现"的（那是通配符噪声），再把真正独特的挑出来**；量太大就 `-of csv -o r.csv` 导出后在表格里按状态码/大小过滤。★ 并发别拉满（`-t` 40 以内），不然自家服务会被自己的"攻击"触发限流 / 封禁。
