# nc · 端口探活 / 收发数据

**用途**：给一个 TCP/UDP 端口发点东西看有没有人应；开临时监听端口；在两台机器间传文件。被叫「TCP/IP 瑞士军刀」—— 手工敲 HTTP 请求、探端口、临时当个极简 server 都用它，脚本里比 telnet 顺手（错误走 stderr，不污染 stdout）。

**用法**：nc [选项] 主机 端口　或　nc -l [选项] [主机] 端口

**常用选项**

探活 / 扫描
- `-z`　零 I/O 模式：只探连不连得上、不发数据（扫描用）　**跟 `-l` 不能同用**
- `-v` / `-vv`　显示详细过程（提示信息走 **stderr**，`-z` 时尤其需要）
- `-w 3`　连接与最终读超时秒数　**不加会挂死**
- `-n`　不做域名/端口名反解

监听
- `-l`　监听模式（收，而不是连出去）
- `-k`　收完一个连接继续听下一个　**需要配 `-l`**；配 `-u` 时能收多个主机的 UDP 包
- `-p 端口`　指定本地端口（监听或用 `-s` 时）；连出去时是**源端口**
- `-s 源地址`　指定本地源 IP

收发 / 传输
- `-N`　stdin 到 EOF 就关闭网络套接字（传文件常用，否则对端不知道你发完了）
- `-q 秒`　stdin EOF 后再等 `N` 秒退出（与 `-N` 相对的老式收尾）
- `-u`　UDP 模式（默认 TCP）
- `-C`　把行尾 LF 发成 CRLF（手工敲 HTTP 有用）
- `-i 秒`　发送行之间 / 多端口连接之间的间隔
- `-I 长度` / `-O 长度`　设 TCP 收 / 发缓冲区大小

协议与转发
- `-4` / `-6`　只用 IPv4 / IPv6
- `-U`　走 Unix domain socket
- `-x 地址:端口`　走代理；`-X 4|5|connect`　代理类型（SOCKS4/SOCKS5/HTTP CONNECT）；`-P 用户` 代理认证用户名
- `-M ttl` / `-m minttl`　设出包 TTL / 丢弃 TTL 过小的入包

**示例**（★ 标出的都在本机 127.0.0.1 实测跑过）

- `nc -zv -w 2 127.0.0.1 22`　这个端口通不通　→ ★ 实测：`Connection to 127.0.0.1 22 port [tcp/ssh] succeeded!`，**退出码 0**
- `nc -zv -w 2 127.0.0.1 9999`　探一个没人听的端口　→ ★ 实测：`nc: connect to 127.0.0.1 port 9999 (tcp) failed: Connection refused`，**退出码 1**
- `for p in 22 80 443; do nc -zvw2 127.0.0.1 $p; done`　连着探几个端口
- `nc -l 127.0.0.1 9000`　在回环上监听 9000（另一头 `nc 主机 9000` 就能对话）　→ ★ 实测：一端发 `hello-nc\n`、另一端收文件里拿到 `hello-nc`，收发通
- `nc -k -l 127.0.0.1 9000`　监听并连收多个连接　→ ★ 实测：先后两次连接，listener 里两条都收到了（`first` / `second`）
- `printf 'GET / HTTP/1.0\r\n\r\n' | nc -w 3 目标 80`　手工扣一个 HTTP 请求
- `nc -N 目标 9000 < 文件`　把文件推过去（对端 `nc -l 9000 > 文件` 接）
- `nc -u -w 2 127.0.0.1 53`　UDP 探一下（DNS 口），`-u` 就是 UDP

**备注**

- ★ 本机是 **OpenBSD netcat（Debian netcat-openbsd 1.234-1）**，选项和传统 GNU netcat **不一样**：**没有 `-e`**（GNU 的 `-e 程序` 反连后门在 OpenBSD 版不存在），`-q` 语义也不同，`-k` / `-N` / `-v` 这些是 OpenBSD 版的行为。查用法以本机 `man nc` 和 `nc -h` 为准。
- ★ **不加 `-w` 会无限挂** —— 对不通的端口直接卡住，脚本里必须带 `-w 2`。
- ★ 判通不通**看退出码**（**实测 0 = 通、1 = 拒绝**）比看输出可靠；`-z` 的提示走 stderr，要重定向 `2>&1` 才看得见。
- ★ **`-l` 与 `-z` 不能同时用**（`-l` 是收、`-z` 是探）；`-k` 必须配 `-l`；`-l` 下 `-w` 超时会被忽略（man 原话）。
- ★ **和 socat 的分工**：nc 胜在轻量、一次性 —— 探活、临时收发、传个文件、手工扣协议最顺手。要**地址转换、双向持久转发、多路复用、串口-TCP、复杂管道**这些，用 `socat` 更对（如 `socat TCP-LISTEN:1234,fork TCP:目标:80`、`socat - UNIX-LISTEN:/tmp/s`）。一句判据：**简单的探活/一次性传数据用 nc，要 fork、要长连接转发、要格式桥接用 socat。**
- ★ 走代理要配全套：`nc -x 127.0.0.1:1080 -X 5 目标 80`（SOCKS5），HTTP 代理用 `-X connect`。
