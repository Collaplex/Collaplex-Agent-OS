# carve backups · 列出改动前的备份

**用途**：看**改之前存了哪些备份** —— 每次写操作都会先备份目标文件，这里列出来（新的在前），带时间、大小。想退回去、想拿旧版本对照，先来这里看有哪几份。

**用法**：`carve -p <文件> backups [--backup-dir 目录]`

**常用选项**
- `--backup-dir 目录`　备份放在别处时指过去（默认在**目标旁边**的 `.carve-backups/`）

**示例**
- `carve -p app.py backups`　看这个文件有哪些备份
- `carve -p app.py backups --backup-dir /tmp/别的备份/`

**备注**：①备份名形如 `20261006-174332-479291-app.py`（时刻精确到微秒，同一秒连改几次也不会互相覆盖）。②退过的备份会改名成 `*.restored` 留档，名单里不再出现 —— 所以看这里最准：还能往回退几步。③备份是**写操作自动做的**，不是另存功能。
