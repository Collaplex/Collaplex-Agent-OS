# carve · 总览: 这个工具怎么用 / 节点 ID 怎么拼 / 按语法结构读写代码

**用途**：这是**总览** —— 这个工具怎么用、命令怎么敲、节点 ID 怎么拼，都在这儿。它管的事：按**语法结构**读写代码文件，按函数/类/方法定位，换实现、加、删、挪；也用来读代码结构（这文件里有哪些函数、谁引用了它）。跟"整行替换"是两码事：这里定位的是**节点**。

**节点 ID 怎么拼**：路径式，看结构长出来的 —— `module`（整个文件）→ `module::函数名` → `module::类名::方法名`。写操作都拿它当坐标。

**用法**：`carve -p <文件或目录> <子命令> [参数]`

**常用选项**
- `-p, --path`　目标文件或目录（也可用环境变量 `CARVE_WORKSPACE`）
- `--read-only`　只读：禁掉全部改动（只想看的时候带上，防手滑）
- `--no-create` / `--no-delete`　禁新建 / 禁删除
- `--no-backup`　写之前不自动备份（默认备份）

**示例**
- `carve -p app.py ls`　先看清结构，再决定动哪儿
- `carve -p app.py show 'module::add'`　看这个函数的源码

**备注**：①输出一律 JSON。②写操作**默认先备份**到目标旁边的 `.carve-backups/`，改错了 `carve undo` 退回去。③**整文件覆盖 / 纯文本替换**不是它的活 —— 那种用 shell（`tee`、`sed`）；它只管"按结构改"。④本机命令名 `carve` 来自软链（工具本体在 `~/桌面/工作区/实验/carve-cli/`）。
