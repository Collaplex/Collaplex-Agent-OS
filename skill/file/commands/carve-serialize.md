# carve serialize · 按当前结构重新生成源码

**用途**：把当前结构**重新生成**成源码文本 —— 改完一串结构之后想看完整的文件长什么样，或者想把生成结果落到另一个路径。

**用法**：`carve -p <文件> serialize [--out 输出路径]`

**常用选项**
- `--out 路径`　写到这个文件；不给就直接打出来

**示例**
- `carve -p app.py serialize`　把整个文件按结构打出来（看改完的结果）
- `carve -p app.py serialize --out /tmp/预览.py`　生成到别处对照

**备注**：①**一般不需要手动跑它** —— 每次写操作（update/insert/rm/mv）都已经把结果同步落盘了。它是给"想核对/想另存"用的。②写完想确认文件到底对不对，用 shell 的 `diff` 跟改之前的备份比（备份在目标旁的 `.carve-backups/`）。③输出可能很长，别整个贴回去 —— 挑关键几行。
