# carve refs · 谁引用了这个节点 / 它引用了谁

**用途**：查引用关系 —— "谁调用了这个函数"、"这个变量在哪儿被用到"、"改了它会影响哪些地方"。动手改代码之前先查一遍，能避免改完把别处弄坏。

**用法**：`carve -p <文件> refs <节点ID>`

**常用选项**
- （没有额外选项，给 ID 就行）

**示例**
- `carve -p app.py refs 'module::blocked_reason'`　看谁在用这个函数
- `carve -p app.py refs 'module::Counter'`　看这个类被谁引用

**备注**：①返回两栏：`references`（它引用了谁）和 `referenced_by`（谁引用了它）。②**改函数/删函数之前先查这个** —— 没有任何引用方，删起来才踏实。③跟 `grep 函数名` 的区别：这里按语法结构认引用，不会被注释和字符串里的同名字骗到。
