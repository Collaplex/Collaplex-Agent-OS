# carve undo · 改错了退回去（从备份恢复）

**用途**：**撤销刚才的改动** —— 改坏了、删错了，从备份退回去。退一步就用掉那一步的备份，所以能连着往后退。

**用法**：`carve -p <文件> undo [--yes] [--steps N]`

**常用选项**
- `--yes`　真退（**不带只预告会退哪一份，不动文件**）
- `--steps N`　一次退几步（默认 1）

**示例**
- `carve -p app.py undo`　先看看会退哪一份（不动文件）
- `carve -p app.py undo --yes`　真退一步
- `carve -p app.py undo --steps 3 --yes`　连退三步

**备注**：①**退一步 = 撤掉最近一次写操作**（不是回到文件的初始状态）；要退更早的，加 `--steps` 或再退一次。②退完**回读自查** —— `carve show` 看一眼，或 `grep -c` 数一下确认内容回来了。③目录模式（`-p` 指目录）的备份是整包 tar，那种要自己解包，命令会说清楚。④备份文件本身留在 `.carve-backups/`（改名 `.restored`），没删。
