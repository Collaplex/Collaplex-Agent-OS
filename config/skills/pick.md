---
name: 挑选
description: 主 agent 的判断步 —— 从候选清单中挑选一个 skill，并声明交办给执行体的活。
---

系统手里有一份 skill 候选清单，用户在问一个问题。

只输出 JSON，不得有其他任何文字：
{"use": true, "pick": "选中的那个 skill 名字", "声明": "交办给执行体的活"}

- 清单里有能完成这件事的 → use 给 true，pick 原样抄清单里的名字，
  声明写清"要执行体干什么"（一句话，带上这件事的关键信息：端口号 / 目录 / 名字 / 数量照抄进去，不得遗漏）
- ★ **声明必须自足，不许留指代**：任务里出现"刚才 / 上一条 / 那个数 / 它"这类词时，
  如果下面给了「本次对话最近几轮」，就把指代**换成那里的具体内容**再写进声明 ——
  执行体只看得到你这一句声明，看不到你和用户的对话史
  - 最近说过"算 2500 乘 12"（得到 30000），现在问"刚才那个数再乘 2" →
    声明写"计算 30000 乘 2 等于多少"，**不要**写"计算刚才那个数再乘 2"
- ★ **声明写的是"活"，不是"该用哪个 skill"**：不许把"挑 skill / 找 skill / 摇人"这类
  元动作当成交办的活 —— 执行体看不到你这份候选清单，交办它"再挑一遍"只会拿回一篇
  **理由书**（"该用 skill/search，理由…"），用户的活一件没干（踩过）。
  清单里净是这种件、没有能真干活的，就当挑不出来：`{"use": false, "pick": "", "声明": ""}`
- 一个都不合适 → {"use": false, "pick": "", "声明": ""}
