# 清洗 · 知识

## 任务目标

从一次问答里**提炼知识点**，存进三层的「知识」条目。
其用途是**细粒度入口**：以后问到某个具体事实，直接命中的就是这一条。

## 触发条件

- **启用**：清洗管线拿到一次问答的全部原话，要抽出可复用的事实时。
- **禁止**：
  - **不许推断、不许补常识、不许臆测** —— 只提炼其中**明确说过**的
  - 不许写指代（"它"、"那个"、"上面说的"）—— 每条须可**独立读懂**
  - 不许合并成一条长文（一条一个事实）
  - 挑不出则交空数组，**不得勉强凑数**

## 输入

二层语料，一行一条，格式 `角色: 内容`。

## 执行步骤

1. 逐行扫描，挑出"说过的事实"。
2. 每条改写成一句**自足的话**（把指代替换成本名）。
3. 同一件事只留一条；最多 8 条。

## 输出格式

只输出 JSON 本体，不要围栏、不要前后解释：

```json
{"知识": ["一条独立的事实", "..."]}
```

## 边界与错误处理

| 情况 | 处理 |
|---|---|
| 话依赖上下文（"就是那个"） | 把指代补全为实体再写；补不出则**丢弃此条** |
| 是提问不是事实（"相机电池还有电吗"） | 不提炼问句；提炼**回答**中的内容 |
| 事实超过 8 条 | 取最具体的 8 条，宁少勿多 |
| 全是闲聊没有事实 | 返回 `{"知识": []}` |

## Few-shot 示例

**入**（同上 10 条原话）
**出**（实测）：
```json
{"知识": [
  "路由器在客厅电视柜下面，挨着光猫",
  "相机电池上周充过，大概还能拍两小时",
  "笔记本是一条 16G DDR5 单通道，B 槽空着",
  "机柜里的 UPS 是威神 BK650，650VA 方波，带交换机和 AP",
  "软路由是 x86 小主机，Celeron N2840 双核，跑 OpenWrt"
]}
```

这几条即合格形态：**无问句、无指代、每条自成一句**。

## 额外：经验条（★ 只从失败/被拦里提炼）

本次问答中若有**被拦、试错、不通**之处，额外提炼"经验" —— 但只写**教训**，
**不得写任何过程描述**：

- ✅ 合格经验条（独立、可用、无过程）：
  - "这台机器上不能用 `rm -rf` 或 `find -delete` 清 /tmp，程序会拦；要清只能逐一点名删"
  - "这台机器的桌面目录是 `~/桌面`（不是 `~/Desktop`）"
  - "看 C/C++ 文件不能用 carve（它只认 Python），要用 head/sed/grep"
- ❌ 不合格写法（是过程，不是经验）：
  - "我先试了 rm -rf /tmp 被拦，又试了 rm -rf /tmp/* 被拦，最后试了 sudo 还是被拦"
  - "尝试了 4 种方法都没成功"

格式与「知识」一致，**一起放进同一个数组**（程序按"独立可读"嵌向量入库）；
确无失败 / 踩坑则**不产出经验条**，不得勉强凑数。

## 注意事项

- 实测：10 条原话 → 5 条知识，**~120 token、1~2 秒**，每条都是原话里明确说过的事实。
- 产出后程序会逐条嵌向量写进三层的「知识」条目（带来源），故"独立可读"至关重要 ——
  带指代的句子嵌入后检索会失效。
- 重复清洗时按来源**先删后插**（避免堆积）。
