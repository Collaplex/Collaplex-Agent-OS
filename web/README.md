# web/ —— 网页版（试水）

命令行那套链原封不动，这里只加一层"浏览器里说话"的外壳。

## 跑

```bash
cd ~/桌面/collaplex_agent
.venv/bin/python -m web.server              # http://127.0.0.1:8791
.venv/bin/python -m web.server --端口 8791  # 换端口
```

## 三块

| 文件 | 干什么 |
|---|---|
| `server.py` | 纯标准库 `ThreadingHTTPServer`：`GET /`（静态 + 图标）· `GET /api/state`（服务/模型）· `GET /api/历史`（会话存档，界面左栏那份）· `GET /api/历史/段?起=&数=`（正文懒加载分段）· `GET /api/设置`（设置页读数）· `POST /api/设置`（**写**接口与开关）· `GET /api/路径?目录=`（列本机目录，**只认本机**）· `POST /api/ask`（一问，回 `text/event-stream`）。**零第三方依赖**。★ 没有"新会话"这类清记忆口子 —— 上下文不自动清空，要清就重启进程。 |
| `bridge.py` | 把 `main.py` / `sub_agent.py` 里现成的函数**搬**成一条事件流（`stage` / `think` / `reply` / `note` / `answer` / `final` / `done` / `error`）。**不含业务规则** —— 判定、挑 skill、递交 exec、入二层库全是调现成函数，`main.py` 一行没改。 |
| `static/` | `index.html` + `app.js`（渲染）+ `style.css` + `vendor/` + 品牌图标（`favicon.svg` / `favicon.ico` / `apple-touch-icon.png`，直接取自官网 `collaplex-site/site/`，页签与顶栏用同一套）。前端库走 **npmmirror 拉的本地包**（markdown-it / DOMPurify / KaTeX / highlight.js，884K），**不引 CDN**。色板取自家官网 `theme.css`（`#0f0f0f` 底 / 单强调色 `#4ade80` / JetBrains Mono）。 |

## 左栏：历史记录 / 设置

- **品牌**：顶栏不再重复产品名，图标 + `Collaplex Agent OS` 归左栏（★ 同一行不重复同一语义）。
- **历史记录 = 跳点，不是"点一条塞一条"**：每轮 **问 + 答 + 过程** 落一行 `state/web-对话.jsonl`（运行产物，已进 `.gitignore`）。
  ★ **过程步骤也入库**（2026-10-09 补）：关掉页面再开，过程不该丢 —— 存档里那串步骤照原样铺回「过程」面板（默认折起来，
  和现场那轮收尾时的样子一致）。单步文字封顶 **4000 字**（一条命令的输出可能几十万字节，原样落盘会把存档撑爆），
  截断处会写明"全文看同一轮里那条【全文】路径"（exec 每跑一条命令都另存了全长输出）。
  `think` / `reply` 这类**流式碎片**在收账时就拼成一步（不然一趟思考会变成几百步）。
  打开网页时正文**只摆最新的一批（10 轮），并把视口钉在最新那轮上**（★ 关掉浏览器的"恢复上次滚动位置"；
  用户没动手之前一路跟着底走，免得内容长高把人顶走）—— 刷新/重开都落在最新一轮。往上翻到顶自动再取 10 轮（懒加载，滚动位置不跳）。
  ★ **离视口远的轮会动态卸载**：只留一个**等高**的壳占位（滚动条长度、滚动位置都不变），视口附近的最多挂 30 轮，
  更远的把内容掏空 —— 50 轮全量历史下 DOM 从 5889 个节点降到 3457（约 -41%），轮数越多省得越多。
  左栏那份清单是**全量跳点**：点哪条就把页面滚到那一轮（没加载的先按段拉回来，被卸载的先补回内容）并高亮。
  分段接口 `GET /api/历史/段?起=0&数=10`（**起**=离"最新"往回数第几轮起，**从 0 开始 = 最新那一头**）。
  卸不卸载纯界面的事，服务端只管按段给（十轮一批。★ 早先那份 6 轮/批的口径已随本条作废）。
  存取全在 `server.py`（`记一轮` / `读历史` / `取一段`），**界面不做任何持久化**。
- **设置**：`GET /api/设置` 的读数**全部从现成配置/函数现算**（`sub_agent.load_config()`、`ContextBudget`、
  各 `config/*.json` 与 `skill/*/resources/*.json` 的开关、索引与语料条数），**不另立一份真相** —— 改了文件这页跟着变。
  `POST /api/设置` 是**可写**的，两片：① 四条接口（主线 / 子agent / 执行体 / 向量模型）写 `.env`（改前自动备份到
  `state/env-backup/`；整组留空 = 回到"跟主线同一套"；密钥留空 = 不动它，回显只给尾 4 位）；
  ② 五个开关（左链检索 / 外援自动触发 / 外援手动 / mtp / 思考路由默认档）写进各自的 json。
  ★ 写入是**逐字节精确**的：只替换目标那个布尔字面量 / 那一行 `KEY=值`，不重排 JSON、不重写别的行。
  ★ **只递交真改过的项**（界面把它们和进来时的原值比一遍），没动的一律不发 —— 点一个开关不会顺手重写四条接口。
  ★ 这些开关都是每轮现读的，**下一问就按新值走，不用重启**。

## 定时任务（设置页那一节 + 过程里的读秒）

- 接口：`GET /api/定时` 看这个进程挂着几条 / 表在哪 / 线程活没活；`POST /api/定时/撤` 撤一条（body `{"id":"…"}`）—— 写操作只走 POST。
- 过程面板：定时读秒走 **`tick` 这一个 kind**，在**同一格**里原地改写（不是每秒新起一格 —— 25 秒实测 = 1 格）；面板折起来时看不见属正常，展开就在。
- 启动时 `定时.进程("web")` + `定时.重挂()`：落冷库 PG 表 `timers`，**按进程键分行**（web 占 `web` 那一行、CLI 占 `cli` 那一行，同一张表不互相覆盖）。
- 一轮的走法：`bridge.一轮()` 开场 `取待办()`（到点的提醒并进这一轮）→ exec 跑完若有**阻塞式**就在这条流里等（每秒吐一格 `tick`）→ 到点再跑一轮把提醒交给主 agent。

## md 渲染四条硬规矩

照 18 家 AI 产品扒来的（证据与对照表见技能 `web-frontend-teardown` → `references/ai-vendor-md-rendering.md`）。
**我们以前 md 渲染做不好的头号原因就是自己拿正则去切 markdown —— 18 家没有一家自己手写解析器。**

1. **别自己切 markdown**：每帧把**整段 buffer** 丢给 CommonMark 解析器，未闭合的围栏 / 半截表格 / 公式由它容错
   （秘塔活体样本：22 秒 2221 字全程没出现过裸 ```）。
2. **块级复用 DOM 节点**：以"**抛光前的原始 HTML**"当 key，一个字节没变的块连节点都不换 —— 不闪、不重排、选中不丢。
3. **新块淡入**：只有新出现的块加 `.md-新`；这轮结束挂 `.md-完成`，把动画全关
   （千问的 `qk-markdown-cache` 就是这个意思：定型的前缀不再重解析、不再播动画）。
4. **后处理走 DOM、不碰字符串**：代码块顶部条 / 复制按钮 / 表格滚动壳 / 外链都在 DOM 上做，跳过 `code`/`pre`
   （秘塔的反面案例：渲染后按文本注入引用角标，python 代码里冒出 `[[32]]`）。

## 输入栏里的本机路径：拖 + 导入面板（2026-10-11）

浏览器**不给网页**本机文件的真实路径（`<input type=file>` 只给文件名，拖拽时只有从文件管理器来的
`text/uri-list` 才带 `file://` 全路径）—— 所以这两条路各走各的：

- **拖**：窗口级 `dragenter/dragover/drop` 一律 `preventDefault`（★ 不挡的话浏览器会**把页面导航走**去
  打开/下载那个文件）；认出 `text/uri-list` 就填带引号的路径，只拿得到 `Files` 就给红字提示"从文件管理器窗口里拖"。
- **导入按钮**（输入框右侧回形针，`Ctrl+O`）：`GET /api/路径` 逐层列目录 —— 点文件就填路径、点目录就进去、
  `..` 上一级、记住上次目录。**服务只读、只认本机**（回环地址 **且** Host 头是本机名 —— 后者挡 DNS rebinding：
  外部网页把域名解析到 127.0.0.1 时，来源地址"就是本机"了，只有 Host 头会露馅）。

**按文件名搜：做过一版，撤了**（2026-10-11，老板："那就不搜索了"）。当时量过的数据留着，将来真要做不重测：

| 走法 | 覆盖面 | 耗时 |
|---|---|---|
| `find` 全盘（冷缓存 / 热缓存） | 110 万 | 13.5s / 5.6s |
| 剪掉 `node_modules`/`.git`/`.venv`/`.cache`/浏览器缓存后 | 37.5 万 | 1.8s |
| 同上，`os.walk` 换成手写 `os.scandir` | 37.5 万 | **0.5~0.6s** |
| 按当前目录搜（`~/文档`） | 1.8 万 | **0.03s** |

结论：**用不着索引**（真要就上 SQLite FTS5 的 `trigram`，本机 3.46.1 有，子串直出）；而且**得用子串不用分词** ——
常找的是 `7z-enc` 这种跨段片段，词级倒排正好跨不上。两条实现口径备用：`DirEntry.is_dir()` 不用 stat，
比 `os.walk` 快 8 倍；目录也该进结果（点它进那个目录接着翻）。

## 坑（真踩过的，都修了）

| 症状 | 根因 | 修法 |
|---|---|---|
| 事件**全收到了**，界面永远转圈、`完成` 等不到 | SSE 发了 `Connection: keep-alive` 却没有 Content-Length、也没分块编码 —— HTTP/1.1 下浏览器只能靠**连接关闭**判"流结束"，而连接一直挂着 | 响应头 `Connection: close` + 收尾 `self.close_connection = True` |
| 代码块高亮在、**顶部条和复制按钮没有** | 代码块是**顶层块**，`querySelectorAll('pre > code')` 只看后代、漏掉它自己；且抛光换壳后返回的仍是旧引用 | `取齐()` 自加后代一起取；`抛光()` 返回"处理后的外壳" |
| 静态 404 把处理线程崩掉 | `BaseHTTPRequestHandler` 的 `send_error` 拿 **latin-1** 编状态行，中文文案直接抛异常 | 404 文案改 ASCII，favicon 回 204 |
| 按元素裁切截图**整张空白** | CDP `Page.captureScreenshot` 的 `clip` 是**页面坐标**，不是视口坐标 | 量的矩形加 `scrollX/scrollY`，并带 `captureBeyondViewport=True` |
| 中文接口名 `GET /api/历史` **404** | 浏览器/curl 会把路径百分号编码，`self.path` 拿到的不是中文原文 | `do_GET`/`do_POST` 里 `解路径(self.path)` 再比路由 |
| 分段接口**参数被吞**（`?起=6` 跟 `?起=0` 返回同一段） | **query 里的中文参数名同样两种形态**：浏览器发百分号编码、curl 发原始 UTF-8 字节，而 `http.server` 按 latin-1 解请求行 —— 只 `unquote` 不够，`unquote` 原始字节串比不到 `起` | 统一走 `解路径()`：先 `latin-1` 编回字节、再 `utf-8` 解、最后 `unquote`；路径与参数名都过它（下一条是它的第二个面） |
| 新加的接口用 `curl` 调直接 **`400 Bad request syntax`**（浏览器里却没事） | 中文参数名 `?根=~` 被 latin-1 解出来带 **`\xa0`（不换行空格）**，而 Python 的 `str.split()` 把 `\xa0` 当空白 → **整个请求行被切碎**，连路由都没进。浏览器发的是百分号编码（`\xa0` 不会出现在请求行里）所以躲过 | **接口参数名一律纯 ASCII**（照老接口用 `?起=` 那套就吃这条）；中文只留在**接口名**（路径段，一定会被百分号编码） |
| 「导入」按钮**一点样式都没有、看着又丑位置又不对**，但按钮在、点了也有反应 | CSS 选择器写成 `#import钮`（拉丁），HTML 里是 `id="导入钮"` —— **对不上**，UA 默认按钮样式顶上来。我只验了"按钮在不在、点了有没有反应"，没读 `getComputedStyle` | 选择器跟 id 一起核；验收脚本加一条 `getComputedStyle` 读数（宽/圆角/边框），改样式必看 |
| 打开「导入」面板**里面一片空白**，也没有任何提示 | 页面是新代码、**web 进程还是改动前起的**（服务端接口不在，`/api/路径` 返 404），而前端只画了个空列表 | 前端按状态码把话说清楚（404 → "这个 web 进程里还没有这个接口…重启一下 web 就好了"）。★ 服务端改动**必须重启进程**，静态页 F5 没用 |
| 改了 `app.js` 页面**还是老样子**（保存键该置灰没置灰） | Chrome 把同 URL 的脚本留在**内存缓存**里，`Page.navigate` 到同一地址可能直接复用（`no-store` 也拦不住内存缓存） | 自测先 `Network.clearBrowserCache`，或给 URL 挂个 `?v=N`；人肉看页面用 `Ctrl+Shift+R` |
| 设置页挂一行只有键、值空白 | 端点通时"说明"是空串，照样画了一行 | 铺设置时空值直接跳过（别挂空壳，看着像漏填） |
| 端点一挂，SSE **断在半路**（浏览器只看见卡住，服务端甩一屏 traceback） | 左链"挑 skill"那一步（`cli.find_skill_for`，也是调模型）**没包** —— 其余各跳都有 try；它只在"模型压根没起"时才会被走到（子agent 先挂 → 回落 → 拿原话去检索 skill → 这一步挂） | 那一跳也包上：说人话（`explain_model_error`）+ 一句"这轮按原样让主 agent 自己答"，然后**继续走回落**而不是抛出去 |
| 跑着时正文区**露一串原始md**（`<调用>find . -name '*.py' …` 整条命令） | exec 那轮"边想边说"的草稿是**模型原文**，里头夹着工具调用标记；原样流进正文区就是那串东西。★ 逐片 strip 挡不住：片段边界会把标记切在两半（`<调`＋`用>ls`＋`</调用`），单看哪一片都不成标记 | 后端加 `native_marks.StreamFilter`（`bridge.py` 起草稿时过一道）：**每次拿"攒到现在的全量"重扫**，完整块整段跳过、开了头没闭合的就停在那等下一片 —— 块前后的人话照流。★ 别在前端做这个：前端只拿到一片片增量，判据容易落空 |
| 改成"跑的时候不写正文"之后，**流式输出没了**（正文区一直空到 final 一次性出现） | 上一行的修法一刀切过头：把 `answer` 事件整个不写了 | 前端恢复 `流式答案.推()`（边流边渲染），干净与否交给后端那道 `StreamFilter`；前端只留一道"从第一处标记起整段截断"的兜底。★ 收尾的 `final` 是定稿，一字不动（正文里真讲这些标记的场合不少） |
| 探针点不动发送按钮（`getBoundingClientRect` 报 null） | 页面被 `app.js` 弹到**启动页**了（`location.pathname === '/'` 且没带 `?直进=1`），启动页上没有 `#问框`/`#发送` | 自测地址统一带 `?直进=1`（`试端到端.py`／`验流式.py` 都改了）；探针里也别 `sleep 3` 就点，先轮询问框出没出 |
| 高亮/悬停**写对了看不见**（computed style 说挂上了，眼睛看不到） | 面板底色 `--card`(#161616)，而 `--card-hi`(#1c1c1c) 跟它**只差 6 级** —— 挂在上面等于没挂。★ 只读 `getComputedStyle` 会骗人：它只证明 CSS 到位，不证明像素上有区别 | 面板里的底色用叠加别用色卡相邻档：悬停 `rgba(255,255,255,.07)`、走位 `rgba(74,222,128,.12)`，差 20 级上下才看得见。验收**必须截图看像素**（这条和"按钮没样式"那条是一对：那次是选择器没匹配上、这次是匹配上了但看不见） |
