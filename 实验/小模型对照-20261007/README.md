# 小模型对照实验（2026-10-07）

老板原话: 「给你几个小时的时间你做对比测试，就按我正常使用的习惯用，可以单轮也可以直接连续百轮去做一下
样本收集和对比实验，到时候我们用大数据分析到底是怎么回事，同时注意一下余额别自己都401了」。

## 题目从哪来
**不用我编的题** —— `题库.jsonl` 59 条全部从三层库/二层语料/网页存档/旧台账里挖出来的
**老板真问过的问题**（`真题-全部.txt` 是原始清单）。每条带标注：该不该动手、该走哪个 skill、
可核判据（正则）、是否破坏性、记忆配对号。

## 四个臂
| 臂 | 题 | 轮数 | 每次带上下文吗 | 测什么 |
|---|---|---|---|---|
| C 一致性 | 硬判据 12 题 | ×5 遍 = 60 | 不带（每遍独立） | 同一句话判几次，判得一样吗 |
| A 单轮 | 全题库 57 题（跳破坏性） | 57 | 不带 | 裸判定 + 裸产出 |
| B 连续 | 题库循环（指代配对题相邻） | 100 | 带（最近 8 轮） | 记忆/指代/长会话漂移 |
| D 云端 | 硬判据 12 题 | 12 | 不带 | 云端对照产出质量（走 DeepSeek） |

## 安全红线（都实测过）
- **钉死本地端点**: 实验自己把 `OPENAI_BASE_URL` 设成 `http://127.0.0.1:8790/v1` ——
  老板的 `.env` 主线现在指着 **MiMo 云**，百轮实验绝不能跑到云上。只有 `--臂 D` 才换云端。
- **不进库**: 给 `bridge.后台入库` 与 `sub_agent.note_activity` 打了空操作补丁 ——
  实验样本不进二层库、不动 `state/activity.json`（实测：二层库仍 2 份、三层库仍 286 条）。
- **额度闸**: 臂 D 开跑前查 DeepSeek 余额，不够留底就不跑；途中超 `--云上限`（默认 1 元）或
  余额跌破 3 元就收手。MiMo 一次都不碰。
- **硬件优先**: 每 20 轮采一次温度/可用内存；显卡 ≥ 85°C 歇 2 分钟。
- **断点续跑**: 跑过的 `(臂, 题号, 遍)` 不再跑 —— 随时中断，重跑接着来。

## 产物
| 文件 | 是什么 |
|---|---|
| `样本.jsonl` | 每轮一条全量样本（判定/挑中skill/声明/命令/首发出错/答案/用时/token/错误） |
| `进度.log` | 人读的一行一轮（含均速与预计剩余） |
| `汇总.md` | 每 20 轮重写的统计表（命中率/真跑率/首发撞墙率 + 该动没动清单） |
| `采样.jsonl` | 硬件采样（显卡温度/利用率/显存/可用内存） |
| `记账.jsonl` | 云端臂逐题 token 与累计花费 |
| `日志/总.log` | 四个臂的原始标准输出 |
