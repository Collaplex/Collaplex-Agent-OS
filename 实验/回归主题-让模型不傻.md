## 漂移是怎么发生的（记下来防复发）
```
起点：模型犯习惯错（习惯:知识 = 96:21 = 4.6:1）→ 结论"要教的是习惯"
  ↓ 第 1 步漂移
"教习惯" → "那就让模型自己学习惯" → 引入赫布循环
  ↓ 第 2 步漂移
"赫布循环" → "那得先有感受器/效应器" → 造感受器 + 效应器
  ↓ 第 3 步漂移
"感受器/效应器" → "还得有激素和内驱力" → 激素 14 种 + 内驱力 + 十万 CNN
  ↓
变成造神经系统（= 论文题目，不是老板的问题）
```

★ **关键错在第一步**：教习惯**根本不需要造神经系统** ——
需要的是把习惯写成**可执行的检查、预布线、提示**。一个字都不该往"造引擎"上走。
