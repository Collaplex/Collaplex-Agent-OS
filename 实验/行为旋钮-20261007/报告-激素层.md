# 激素层（14 种，按"共传递是常态"搭）—— 试验台结果

## 搭法（照老板给的方向）
| 类别 | 种数 | 引擎里怎么落 |
|---|---|---|
| 小分子（10~15，快·毫秒级） | **骨架 8** | 每种直接管一个具体参数：Glu 兴奋增益／GABA 抑制／DA 学习率／NE 探索率／5-HT 改动量预算／ACh 稀疏闸／组胺 觉醒度／腺苷 疲劳 |
| 神经肽（60~100+，慢·扩散远·持久） | **修饰 4** | 不直接改参数，改"骨架激素的效力"：催产素 信任→放宽探索／神经肽Y 食欲→多试／胆囊收缩素 饱腹→早收手／内啡肽 奖励基线。**有积分、起效慢**（每轮朝目标靠 15%） |
| 气体（NO/CO/H₂S，无受体） | **1** | 不走通道：按浓度直接加到邻近单元 |
| 脂类（内源大麻素，逆向传递） | **1** | 输出差 → 反过来压输入侧强度（"少放点"） |
| 共传递是常态 | — | **复配**：每个参数 = 多种激素 × 各自受体权重求和（学习率 = DA×(1+内啡肽)×(1−腺苷)） |

试验台＝赫布扩展那版（512 单元 / 6,656 条边 / 基线 83.3%），30 轮训练 + 一轮首步命中评估。

## 结果
| 档 | 命中 | 权重差 | 读法 |
|---|---|---|---|
| 基线（骨架默认·修饰0） | 75.0% | +9.95 | — |
| **GABA↑ 抑制×3** | **91.7%** | +10.40 | ✓ 最有效：狠压"没被选中的" → 干扰族被压下去 |
| DA↑ 学习率×3 | 58.3% | +27.12 | ✗ 过冲：权重差暴涨但判断变差（幅度大 ≠ 好） |
| NE↑ 探索 0.5 | 41.7% | +9.44 | ✗ 乱试太多 |
| Ado↑ 疲劳 0.8 | 66.7% | +1.86 | ✓ 学得少（权重差掉到 1.86，一致） |
| 5-HT↑ 改动预算 0.02 | 66.7% | +7.66 | ✓ 限改动 → 学得少，一致 |
| ACh↑ 稀疏闸×4 | 75.0% | +9.95 | 无变化：这个规模下稀疏度不是瓶颈 |
| Glu↑×3 / 组胺↑×3 | 75.0% | +9.95 | 无变化 ⇒ **我的实现问题**：读出常数增益对 argmax 没影响 |
| 修饰 4 种全开 | 50.0% | +29.25 | ✗ 催产素放大 NE ⇒ 探索过多 |
| NO↑ 气体扩散 0.5 | 58.3% | +8.80 | ✗ 扩散把激活抹平了 |
| 2AG↑ 逆向 0.5 | 66.7% | +7.94 | ✓ 压输入强度 → 学得少，方向一致 |
| ★复配 DA+内啡肽+腺苷 | 50.0% | +27.48 | ✗ 这组没赢 |
| ★单打 DA 2.0（对照） | 58.3% | +18.30 | 复配反而更差（内啡肽把学习率又推高 ⇒ 过冲更狠） |

## 三个结论
1. **激素层确实能造出差异**（14 档里 12 档有变化），而且方向与教科书一致：
   抑制（GABA）压干扰最有收益；学习率/探索过大多必变差；疲劳（腺苷）、限改动（5-HT）都表现为"学得少"。
2. **共传递复配这一组没跑赢单打** —— 但原因是**组合不巧**（内啡肽把学习率又推高 ⇒ 过冲），不是复配机制错。
   要判"复配有没有优势"，得把复配组设成**相互靠配**的组合（如 GABA↑ + 腺苷↑ + 5-HT↑：压制 + 降速 + 限改动）。
3. **两个无效项是我的实现问题**：Glu/组胺是"读出常数增益"，对 argmax 完全等效（除非配 softmax 温度）；
   它们该改成去影响**发放阈值**（什么时候出手），而不是放大数值。
