# 解码器（内部活动 → 文字）+ 当"学会没有"的探针

## 为什么非要这一层
老板问："效应器输出的不本来就是文字吗"
—— 对，但那是**从外面看**。里面看，效应器吐的是**内部活动**（一堆单元亮灭），中间必须有一层映射：

| 做法 | 后果 |
|---|---|
| **写死的表**（13 个动作 → 13 条命令） | 它只会说我会的那几句，而且**"学会没有"永远说不清** —— 字是我给的 |
| **学出来的映射**（内部活动 → 词） | ① 字是它自己的 ② **这层映射本身就是探针**：教过的能对上、没教过的对不上，一眼看出学到什么 |

## 设计（全部从数据长，不引外部词表）
- **字表 58 字**：题目里出现过的字（语料长它就长 → "不限数量"）
- **词表 28 词**：命令里出现过的词 + `<结束>`（同上）
- **感受器 178 位**＝教入口（题字 58 槽）＋ 自省入口（我刚吐出来的词 28 槽）＋ 位置入口（3 槽），每槽隔一格防 CNN 单元串扰
- **内部**：唯一的 CNN 单元（4 参数）
- **解码器**：岭回归闭式解 `D = (HᵀH + λI)⁻¹HᵀY`（λ=0.01）——教学 24 条样本 → 178×28 = 4,984 个数
- **解码**：逐词自回归，直到吐出 `<结束>`

## 结果（12 题，教 8 留 4）
| 类别 | 题 | 答案命令 | 它吐出来的 | 判定 |
|---|---|---|---|---|
| 教过 | 根分区还剩多少 | df -h | df -h | ✅ |
| 教过 | 内存还剩多少 | free -h | free -h | ✅ |
| 教过 | 杜子端口有没有在听 | ss -ltn | ss -ltn | ✅ |
| 教过 | 现在几点 | date | date | ✅ |
| 教过 | 系统跑了多久负载多少 | uptime | uptime | ✅ |
| 教过 | tmp 占多大空间 | du -sh /tmp | du -sh /tmp | ✅ |
| 教过 | 有几个进程在跑 | ps aux | ps aux | ✅ |
| 教过 | 本机 IP 是多少 | ip -brief addr | ip -brief addr | ✅ |
| **留出** | CPU 几核 | lscpu | **date** | ❌ |
| **留出** | 内核版本 | uname -r | **df -h** | ❌ |
| **留出** | 有哪些服务在跑 | systemctl … | **ps aux** | ❌ |
| **留出** | 日志最后几条说了什么 | journalctl … | **date** | ❌ |

**重建 8/8 ✓　泛化 0/4 ✗　合计 8/12 = 66.7%**
**二级判据**（不用标准答案，只看它吐的命令真跑一遍能不能答到那道题）：**8/12 = 66.7%** —— 正好等于教过的那 8 条 ⇒ 判据自洽 ✓

## 结论：**记住了，没懂**
它解错的方式很说明问题：`CPU 几核`→`date`、`内核版本`→`df -h`，全是"**教过的题里字面最像的那条**"。
因为感受器里只有**字**没有语义："核"这个字在教过的题里从没和 `lscpu` 搭档过，它只能去找"看着像"的。

技术账：教学样本 **24 条** vs 解码器 **4,984 个数** ⇒ 严重欠定，λ=0.01 的正则把它压成了**最近字匹配** ⇒ 泛化必然为 0。

## 价值：这是一台"学会没有"的仪器
插上去，"记住"和"懂"立刻分得开。**以后每版都插一次。**

## 下一步（按依赖排）
1. **感受器要有语义**（不只是字）：同一件事的多种问法都教（"CPU 几核"/"处理器核心数"/"几个核"），或上嵌入 —— 泛化全靠这个
2. **内驱力×任务复配**（解"噪声电视问题"）
3. **教法要变**：不只教"答案"，要教**问法的多样性**，否则永远是背题
