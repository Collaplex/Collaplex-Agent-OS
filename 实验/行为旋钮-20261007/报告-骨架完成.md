## 第③层：奖励信号换了之后才有区分度

主判据 = **推荐的做法的"判据贡献率"**（该做法出现过的轮里，判据命中的比例）；基线 = 全体做法平均。

| 档 | 判据贡献率（未归一） | 判据贡献率（去掉频率红利） |
|---|---|---|
| 基线（全体做法平均） | 39.6% | 39.9% |
| 静态（只按"一起出现过"） | 45.8% | 42.4% |
| 只加强（按奖励加强） | 49.2% | **47.2%** |
| 完整（加强+抑制+衰减） | 49.2% | 46.8% |

**读点**
1. **奖励 > 共现 > 基线**，去掉频率红利后依然成立（47.2 / 42.4 / 39.9）→ **奖励信号是有效的** ✓
2. **"完整"反而略差**（46.8 < 47.2）→ 加抑制+衰减在这个规模上没收益，与类脑 MVP 里"**学新忘旧只在规模上出现**"一致 ✓ 数据量不够 ✓
3. 考题只有 135 步 → 置信度有限，要更大数据才算数 ✓
4. 顺带读数：**只有 40% 的命令输出进了最终答案**（939/2343）→ 60% 是探索或白跑 ✓ 可当效率指标。

## 已确认的结论（跨实验一致）
- **"一起出现"不等于"有用"**：共现那档比基线只高一点点，而按"有没有用/判据中没中"当奖励就明显高一截 ✓ 这就是"**得监督效应器**"的实证 ✓
- **要教的是两条习惯**（比原先一条更准）：① 别在同族里穷举（14% 的情况，但 100% 再被拦）② 换了之后别丢目标（86% 会换，但常换成"另一件事"）
- **最高频的坑是"爱加 sudo"**（63 次，比 rm 族都多）
- **旋钮不需要很大**：2.5万 → 200万 才有明显提升，拐点在百万参数级 ✓ CPU 可训 ✓
- **桥（沿共现边一跳）贡献最大**：旋钮的均衡正确率 38.9% → 45.6% → 62.8% ✓
